# AUDIT-IMPL60 —— 搜索：列出所有关键字匹配（去重/排序/分组/计数/诚实边界）

- 基线：`main` @ `47fb254`（v0.95.0），`npm run check` = **691 × 2 全绿**
- 结果：**697 × 2 全绿**（+6 条断言）；`build.mjs` **未触碰**（73 项片段校验通过）；未 commit / 未装 / 未动 profile / **未重启服务**
- 实验隔离 `DSH_HOME=/tmp/search-1`；未手工写 `~/.dsh`

## 1. 一行结论

搜索候选的两处截断都去掉了（路由不带要数参数 + 宿主映射里**写死 10 条**），调用方一次要 50 条并去重、按"完全→前缀→包含"排序、按市场分组、显示「共 N 条」；拿满上游上限时如实写「上游本次上限 M 条」，失败显示原因而不是空列表。

## 2. 现状定位（上限到底来自哪）

| # | 位置 | 事实 |
|---|---|---|
| ① | `src/host/routes.ts:918`（`/tradewatcher/suggest`） | 只有一个 `q` 参数，**没有 count/pz** ⇒ 调用方无法要求更多 |

| ④ | `src/client/ui.tsx`（`SuggestInput`） | 客户端**没有**截断（拿到几条渲染几条）⇒ 不是客户端上限 |

**实测命令与结果**（改前，跑着的宿主是旧构建）：

```
$ curl -s 'http://127.0.0.1:3080/tradewatcher/suggest?q=中远'
  → 10 条（600026/600428/601866/601919/002401 …）
$ curl -s '.../suggest?q=中远海能'   → 2 条（600026 A + 01138 H）
```

**上游能力实测**（`searchapi.eastmoney.com/api/suggest/get`，直接打上游）：

```
count=14  → 14 条      count=30 → 18 条      count=50 → 18 条      count=100 → 18 条
?…&pn=2   → 与 pn 无关，返回同一批 18 条
```

⇒ **上游没有分页参数**（`pn` 无效），同一输入的上限就是它自己给的那一批（本例 18 条）。
所以"翻页取全"在这里**退化为**：一次把要数提到 50（≥ 上游能给的量）⇒ 能拿全；当返回条数**正好等于**要数时，我们**无法排除**还有更多 ⇒ 如实披露（见 §4）。

# 追加（复查批）：为什么界面仍显示"共 10 条 · 上游本次上限 10 条"

- 基线：`697 × 2` 全绿 → 追加后 **698 × 2 全绿**（+1 条**结构性防回归**断言）
- `build.mjs` 未触碰；未 commit / 未装 / 未动 profile / **未重启服务**；隔离目录 `DSH_HOME=/tmp/sug2-1`

## 1. 结论（与初判不同，给证据）

**不是调用方传了 10** —— 界面侧只有一个调用点，它传的是 50：

```
$ grep -rn "\.suggest(" src/client/          # 全部界面调用点
src/client/ui.tsx:70:      .suggest(q, 50)     # SuggestInput：自选页「添加证券」与持仓页「加入分组」共用
```

**真正的原因：跑着的宿主进程仍是旧构建，新代码只在磁盘上**。证据：

```
$ curl -s '127.0.0.1:3080/tradewatcher/suggest?q=中远&count=50' | jq 'keys, (.hits|length)'
["hits"]          ← 旧路由：不认识 count，也不回 requested/truncated
10                ← 旧代码在映射里写死 `if (out.length >= 10) break`
$ grep -c 'requested: count' lib/index.js
2                 ← 磁盘上的新构建**已经**有新代码（`npm run check` 的构建步骤产物）
```

⇒ 客户端热更新（页面刷新即拿到新 bundle）**但宿主进程不会热更新**，于是新客户端把旧宿主的 10 条如实写成
「共 10 条 · 已显示全部 10 条（上游本次上限 10 条，可能有更多）」。**这句话本身是对的**（旧宿主确实只给 10 条且拿满上限），它只是暴露了宿主未重载。

**要让界面显示 17 条，唯一剩下的一步是让宿主进程加载新构建**（重启/重载服务）—— 本轮约束是**不许我重启**，所以这一步留给你或用户。
