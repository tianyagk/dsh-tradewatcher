# K 线左下角提示框移除（键盘提示删除 + 区间统计并入口径行）

> 用户裁决（2026-10-22）：K 线图左下角那个提示框与鼠标跟随的细节卡重叠，必须移除。
> 红框里有两类内容：
>   · **删除**：键盘快捷键整段（`←/→ 平移` / `Shift 加速` / `Enter` / `Esc` / `+/- 缩放` / `Home/End`）连浮层容器；
>   · **保留**：`区间内 B/S 笔数`、`净买入`、`买入均价 / 卖出均价` —— 合并进图上方**已有那条**状态行，
>     用 ` · ` 追加；**不新增第二行、不新增浮层、不加悬停**。

## 1. 原因

该提示是**常驻**的键盘说明 + 区间统计（源码里挂在图表容器的 `title` 上，浏览器原生 tooltip 与
`TipCard` 细节卡在同一区域，必然重叠）。键盘操作属**一次性学习成本**，不必常驻；区间统计属数据事实，
应放到已有的口径行里，而不是第二块浮层。

## 2. 删/搬逐条

| 内容 | 处置 | 落点 |
| --- | --- | --- |
| `键盘：←/→ 平移（未显示卡片时）／移动光标并显示细节卡（Shift 加速），Enter 显示，Esc 隐藏，+/- 缩放，Home/End 到两端` | **整段删除**（含图表容器上的 `title` 属性） | 不再存在 |
| 滑块 aria 里的 `Shift 加速` | 删除该措辞（`可视区间（方向键调整）`） | `kline.tsx` RangeSlider |
| `区间内 B 27 笔 / S 18 笔` | 搬进状态行 | `klineStats.ts` `rangeStatsText` → `caliberWithStats` |
| `净买入 12000 份/股` | 同上 | 同上 |
| `买入均价 19.696 / 卖出均价 19.527` | 同上（两侧都有成交才显示） | 同上 |
| `区间外另有 N 笔`（读屏用） | 保留在 `aria-label`（依赖当前缩放窗口，别处没有） | `kline.tsx` `bsHint` |
| 细节卡 `TipCard` | **保留**（鼠标跟随的悬停卡） | `kline.tsx` |

状态行示例（**一行**）：

```
日K · klt 101 · 前复权 · 截至 10-22 13:08 · 区间内 B 27 笔 / S 18 笔 · 净买入 12000 份/股 · 买入均价 19.696 / 卖出均价 19.527
```

## 3. 实现

- 新增 `src/client/klineStats.ts`（纯函数，无 React）：`tradeMarkersOf` / `tradeStatsOf` / `rangeStatsText` / `caliberWithStats`。
- `KlineChart` 把可见窗口 `[s,e]` 通过 `onRangeChange` 上报（回调走 ref，父组件不需要 memo）；抽屉据此计算统计，
  并 `caliberWithStats(caliberLine(), stats)` 追加到**同一条** `tw-caliber`。
- 图表容器不再有 `title`；`aria-label` 仍含完整读屏摘要（区间内/区间外笔数）——读屏可达，但不渲染任何浮层。
- `build.mjs` 锁定的两句字面量（`区间内无买卖点` / `区间外另有`）**原样保留**（现在分别在 `rangeStatsText` 与 `bsHint` 里）。
