## 1. 诊断（复述并给出硬证据）

- 旧口径：`timeCoefficient(早盘) = 0.4` ⇒ 等级线被抬成 `35/0.4 = 87.5`、`55/0.4 = 137.5`，而四项权重上限只有 **71.7** ⇒ **早盘数学上不可达**。
- 本机副本实测（全日志 09:30–10:29 共 **65** 条交易时段样本，`rawScore × coef` 的最大值 = **23.5**）：
  没有一条能碰到 87.5 这条早盘线 ⇒ **真信号也被一起压掉**（不是"早盘没信号"，是"线够不着"）。
- 修法（用户指定，未另起机制）：把"早盘量能天然偏小"这件事交给**同刻度基线**（同一时刻的历史分布），
  而不是交给一个全局系数。

## 2. 实现（复用既有结构，未新增功能）

| 项 | 做法 |
|---|---|
| 基线数据 | 复用既有 `fetchProgressCurve`（新浪 5 分钟 K 线，实测 **126 天**历史）⇒ 除均值曲线外**新增逐 slot 的 σ** ⇒ 存 `progressSd`（长度固定 49，**天然有界**，与 curve 同一天更新一次；写入仍走既有 `updateJsonLocked` + 读守卫） |
| z | `sameSlotZ(progressNow, μ, σ, days)`：`z = (今日累计额÷20日均额 − 同 slot 近 20 日 μ) ÷ 同 slot σ`，夹在 ±5；`days < 20` 或 `σ < max(1e-4, 5%μ)` ⇒ **null**（回落，不写 0、不编 z） |
| 量能因子 | 有 z ⇒ `f1 = interpScore(z, [0.75, 1.5, 2.5]σ)`；无 z ⇒ 旧的 x 倍数锚点（`RESCUE_CALIBRATION.f1`）。两套刻度在因子行里**分开标注**（`z=…` / `…x`），不可直接比 |
| 等级线 | **不动**：有基线时 `coef = 1` ⇒ 线就是 `35/55`；基线不足时照旧按系数抬高（旧行为） |
| 时点系数 | 降级为**兜底**：只在基线不足时参与；归因里写「生效时点系数 …；量能口径：…」 |
| 展示 | 复用「因子 N/4」与既有归因/悬停；ETF 行新增 `volumeZ`（同一表格的既有列位，不新增面板） |

## 3. 回放对照（本机日志**只读副本**，窗口 = 最近 9 个有样本日、321 条样本）

| 口径 | 改前 | 改后（见下方假设） |
|---|---|---|
| 日级最高等级分布 | `{0:3, 1:3, 2:3}`（逐日 1 2 0 0 1 2 1 2 0） | `{0:2, 1:5, 2:2}`（逐日 1 1 0 0 1 2 1 2 1） |
| **早盘 09:30–10:29 触发率** | **0/65 = 0.0%** | **45/65 = 69.2%** |
| 全天触发条数 | 156 | 210 |

**回放里的"改后"是**：真实日志样本 + **真实均值曲线**（标定 `progressCurve`）+ **声明过的离散度假设** σ = 25%×μ、n 视为 20 天。
本机日志里**没有逐日同 slot 曲线**（所以真实 σ 现在还没有），因此这一列不是"真机 20 日基线跑出来的"，只是**同一批真实样本下的口径推演**。σ 敏感度（早盘 z ≥ 0.75、即量能因子 ≥ 40 分的样本占比）：

| σ 假设 | 25%×μ | 50%×μ | 75%×μ | 100%×μ |
|---|---|---|---|---|
| 早盘触发占比 | 75.4% | 72.3% | 63.1% | 44.6% |

⇒ 改后的绝对触发率**强烈取决于真实 σ**；真机 σ 由上游逐日曲线算出（126 天 ⇒ 样本充足），而不是本回放的假设值。
**本机当前状态**：`progressDays = 126`、`progressSd` 字段**尚不存在**（本批新增）⇒ 在**下一次每日标定**写回 σ 之前，
真机走的是**兜底**（行为与改前一致）；写回之后 n = 126 ≥ 20 ⇒ 基线生效（不用等 20 天）。

## 4. 两条合成用例（验收核心）

| 用例 | 输入 | 结果 |
|---|---|---|
| ① 早盘异常放量 | 09:40（旧系数 0.4）+ `volumeZ = 2.2`（n=20）+ 常规脉冲/背离、持续性样本不足 | **L1**（`raw = 40.0`，线 35/55）⇒ **早盘不再静默** ✓ |
| ② 早盘量能正常 | 同一盘面，只把 `volumeZ` 换成 `0.1` | **L0**（`raw ≈ 19.6`）⇒ **不误报**，且同一盘面 z=2.2 时确实出等级（差异来自量能刻度，不是门槛） ✓ |
| ③ 冷启动 | `volumeZ = null, volumeZDays = 6` | 生效系数仍 0.4、线仍被抬到 87.5、归因写明「同刻度基线不足（6/20 日）⇒ 本次用时点系数 0.4 替代」 ✓ **不静默** |
