# dsh-tradewatcher 待开发清单（ROADMAP）

本清单回答一个问题：**对标爱盯盘（浏览器扩展）之后，我们该补什么、补到什么程度、按什么顺序补。**

对标对象：爱盯盘（Edge/Chrome/Firefox 扩展 + VS Code 版，面壁投基开发，2.36.0；招牌能力是浏览器角标、置顶置底、摸鱼主题、云同步）。

三类条目**不进清单**：① 依赖浏览器扩展形态才能做的（角标常驻、置顶置底、跨页面注入）；② 数据源已被监管层停止披露的（北向实时净买额）；③ 与 README「明确不做的项」重复的（再引图表库/状态管理库、CI 供应商、账号体系）。每条给：目的 / 做什么 / 数据源 / 验收 / 工作量（S ≈ 半天，M ≈ 1–2 天，L ≈ 3 天以上）。

**排序原则**：先让已有数据不说谎（口径与状态）→ 再把状态外化到一眼看得见 → 最后做加法（新市场、新面板）。加法越多，口径不清时的误导越大。

## P0（先做：都在「让已有数据不说谎」这一层）

### P0-1 读工具「数据时刻」统一契约（S）
**目的**：agent 读到的每个数都能回答"这是几点、什么源、可不可信"。
**做什么**：7 个读工具（portfolio / ledger / watchlist / quotes / calendar / rescue / models）统一返回 `asOf`（数据时刻）/ `stale`（是否降级）/ `source`（em|tencent|sina|lkg）/ `missing[]`（拿不到的字段与原因）；`portfolio` 增 `fxMode` 与 `unpriced[]`；`rescue` 增 `activeWindow`（采样窗口）与 `calibratedAt`。
**数据源**：现有内部状态，无需新源。
**验收**：任一工具返回不得出现无出处的数字；`missing[]` 要能解释每个缺失字段（"上游没有这份数据" ≠ "这次暂时失败"）。
**注意**：`stale`（降级复用）与 `cached`（休市定稿零回源）语义不同，两个字段都要留。

### P0-2 卡片四态标记与来源徽章（S）
**目的**：一眼分辨卡片是实时 / 延迟 / 定稿复用 / 没有。
**做什么**：每张行情卡加 6px 状态点——绿=实时、黄=延迟（超过刷新间隔 3 倍）、灰=定稿复用（`cached`）、红=缺失；tooltip 给源与时刻；列表头汇总 `12/23 实时 · 9 延迟 · 2 缺失`，缺失项可点开看原因。
**数据源**：现有 `/quotes` 的 `asOf`/`stale`/`cached`/`source`。
**验收**：四态色点都要真实出现过；汇总数字与逐卡状态**必须加得上**；未开盘时不得显示绿色。

### P0-3 侧边栏徽标（S）
**目的**：不打开面板也知道发生了什么（对标它的浏览器角标）。
**做什么**：徽标取护盘等级或持仓当日涨跌——护盘 ≥「疑似护盘」显示「护」；否则显示持仓当日盈亏率（带符号）；收盘后加后缀「收」；隐身视图下只显示点位、不显示金额。
**数据源**：现有 rescue 快照 + portfolio 当日盈亏。
**验收**：徽标数字与面板顶部数字必须同源（同一次取数结果，不许各算一遍）。

### P0-4 非活跃时段显式态（S）
**目的**：收盘/午休时分数位为空，必须说清是"暂停采样"而不是"坏了"。
**做什么**：非采样时段分数位显示 `—`，旁注 `采样暂停 · 下次 10-09 09:25`；`gap` 只反映当日真实失败。
**验收**：暂停时段不得出现「采样缺口」字样；断言要覆盖到 UI 层。

### P0-5 图表数据口径条（S）
**目的**：图上每个数都能被追问"哪根、什么口径、更新到几点"。
**做什么**：详情图顶部一行 `日K · 前复权 · 截至 10-09 14:31（当根未收盘，MA 已含）`；非交易时段显示 `已收盘定稿`。
**验收**：口径条字段与实际取数参数同源（不许手写死）；MA 是否含未收盘当根必须写明。

### P0-6 成本口径切换联动说明（S）
**目的**：摊薄/移动加权两口径并存，切换不能数字跳变且无解释。
**做什么**：切换时 toast 报差值（`口径切换：成本 X → Y，影响浮盈 ±Z`）；两口径共用同一成本函数，切换只换参数。
**验收**：任一持仓两口径的成本都能复算；切换后总额变化等于逐项差值之和。

### P0-7 评分可解释性与阈值漂移监控（M）
**目的**：护盘评分现在只给总分与六因子，缺"这一分是谁加的"。
**做什么**：因子表加贡献度列（权 × 因子分），断言"贡献度求和 == 总分 ±0.5"；每次出分写一条 rescue-log（含各因子原始值与当次阈值），阈值漂移时可回溯。
**验收**：任意快照可复算总分；阈值改动后能从日志看出分差从哪天开始偏。

### P0-8 紧凑 / 隐身视图（M）
**目的**：对标"一键摸鱼"。
**做什么**：三档 `完整 / 紧凑 / 隐身`（Alt+M 轮换，prefs.viewMode 持久化）；紧凑=去说明文字与脚注；隐身=金额用 `¥••••` 之类的模糊表示、涨跌色转灰阶；金额统一走格式化出口（一处改、全局生效）。
**注意**：隐身只影响**显示**，不许影响取数、告警与 agent 工具返回。
**验收**：三档切换不触发额外请求；隐身态下页面不出现任何绝对值金额。

### P0-9 多设备导出 / 导入（M）
**目的**：对标它的云同步，但不做账号体系，走文件。
**做什么**：导出 watch/positions/ledger/prefs 打包 JSON，带 `schemaVersion` 与内容校验和；导入前预览冲突（行数、最新时间），覆盖前写 `.bak`；**账本重放不一致直接拒绝导入**（宁可不导入，不能导入一份算不平的账）。
**验收**：导出 → 清空 → 导入后持仓视图逐项一致；损坏/半截文件必须被拒并给出具体原因。

### P0-10 内嵌 iframe 三态降级（S）
**目的**：云图面板现在"白了就是白了"，分不清没网还是站点挂了。
**做什么**：懒加载 + 8s 超时占位（显示域名与最后成功时间，不用裸心跳文案）；三态=加载中/已加载/超时；超时态给一次「重试」。
**注意**：iframe 源站是第三方，本仓库只做展示与降级说明，不抓取它的内容。
**验收**：断网时显示超时态与最后成功时间，而不是空白 iframe。

### P0-11 写工具最小权限与可撤销（S）
**目的**：agent 能写数据（日历等），写错要能退。
**做什么**：写工具记录 `by`（会话 id）；提供 undo（按 id 反向操作）；同秒 3 次以上写入节流；改到不该改的文件时拒绝并说明原因。
**验收**：任一写入都能撤回到写入前状态；节流触发时返回明确错误，不静默丢弃。

## P1（增量：口径显式化 + 共同功能补强）

### P1-1 分时缩略图叠加信息（M）
缩略图叠加均价线与开/高/低、振幅（hover 时显示）；图上不加常驻文字（密集布局里加字就是噪音）。

### P1-2 B/S 去噪与区间图例（M）
同一天多笔合并为 `B×3`；缩放区间外给出图例（净买入/净卖出/成本变化），避免"点位看着多、其实只有两笔"。

### P1-3 板块 alpha 口径显式化（S）
板块涨跌缺失时显示 `—` 并注明原因，**禁用 0 代替**——0 会被读成"没涨没跌"，那是错的信息。

### P1-4 自选异动提示（S）
自选里突然放量/异动用呼吸高亮 + 徽标队列；同一条目静默 30 分钟，避免刷屏。

### P1-5 可用数量与费用列（M）
持仓表加「可用数量」（A 股 T+1、ETF/港股 T+0 白名单）与「费用」列（费用合计 + 占成交额比例）。

### P1-6 不计入总额可下钻（S）
总额旁「不含 N 项」可点开，列出被排除的持仓与原因（无价/退市/口径不符）。

### P1-7 资金流排行口径与时刻（S）
15:00 后停更改标「定稿」；金额与占比两种排序可切；来源标注沿用现有 `flowSource`。

### P1-8 涨跌家数历史分位（M）
收盘后每日存一条快照，给出当前值在近 N 日的分位；`N<5` 不显示分位（样本太少的分位是噪音）。

### P1-9 概率面板统计护栏（S）
`N<30` 加「样本少」标记；概率给 Wilson 95% 区间——20 个样本的 80% 与 500 个样本的 80% 不是一回事。

### P1-10 日历「可能变更」标记与勾稽（S+S）
自动事件改期给 diff 与历史；日历与持仓/自选勾稽（三组排序，格点实心=有持仓、空心=仅自选）。

### P1-11 持仓跨市场汇率折算（M）
总额口径行 + `fxMode` 三态（不折算/固定汇率/实时汇率）；**实时汇率源待探活**。不折算时总额必须标「不含港股市值」，而不是按 1:1 悄悄加进去。

### P1-12 南向实时 + 北向收盘口径（S）
南向（港股通）盘中披露未暂停，可做实时。**北向自 2024-05-13 起港交所停止披露盘中买入/卖出成交金额与成交总额**，改为收市后披露成交总额及总笔数、ETF 成交总额、当日前十大成交活跃证券；盘中仅当额度余额 <30% 时公布余额（≥30% 显示"额度充足"）。所以北向只做「收盘后口径 + 额度状态」，任何"实时北向净买额"都不做。

### P1-13 港/美股自选（S）
支持港美股加自选；"当日涨跌"必须按**该市场的交易日**算（美东/香港日历），时间口径要从现在的单一 `Asia/Shanghai` 扩成「市场日历 + 按北京时间显示」。

### P1-14 场外基金净值 + 估值双口径（M）
持仓市值**只用净值**并标 `T-1`；估值只作盘中参考、单独列且明确标"参考"。两个源都**待探活**。

## 明确不做（附理由，避免反复评估）

- **系统托盘 / 桌面通知徽标**：宿主不常驻托盘，硬做只会制造无效通知。
- **账号体系 + 自建云同步**：明文 JSON + 单机是现在的安全模型；引入账号等于引入凭据与自建服务，收益不抵风险（替代：P0-9 文件导入导出）。
- **券商开户导流**：与工具定位无关。
- **实时北向净买额**：监管层面已停止披露，做不出来。
- **自动交易 / 下单**：本插件只读行情与记账，不承担下单责任。
- **全市场逐笔与 Level-2**：免费源没有，付费源违背本仓库定位。
- **抓取 / OCR 第三方页面**：一改版就坏，且容易触发封禁。
- **涨跌预测式「AI 荐股」**：概率面板给的是"历史同类情形的频率"，任何预测话术都是越界。
- **再引入图表库或状态管理库**：零新增依赖是硬规矩，现有自绘图表已够用。
