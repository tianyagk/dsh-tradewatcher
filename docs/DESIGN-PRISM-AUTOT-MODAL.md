# 设计稿 v2：棱镜「自动做T」= 弹窗卡片（人类只开关，其余全是展示）

> 状态：**仅设计，未实现**。本版取代上一版弹窗设计的「参数配置」章节。
> 原型：`docs/prototype/prism-autot-modal.html`。

## 0. 一句话

自动做T 是模拟盘的附加功能：**人类唯一能操作的是"某个持仓要不要做T"这个开关**；
其余板块全部用于展示 Agent 当天怎么判断、做了什么、结果如何。

## 1. 人机边界（这一版的核心）

| 谁 | 能做什么 | 不能做什么 |
| --- | --- | --- |
| **HUMAN** | 逐个持仓打开/关闭做T；关闭时撤销该标的未成交 T 腿 | 不设置单轮规模、价差阈值、轮次、时间窗；不选方向；不改价 |
| **Agent** | 每天判断每只开启做T的持仓：做不做、正T/反T、买卖价、股数、失效条件 | 不能突破引擎硬约束（T+1、净持仓不变、止损/闸门、费用覆盖） |
| **引擎** | 校验、挂条件单、到点回补、结算、写决策流 | 不自行决定方向与价位 |

**为什么**：做T 是 Agent 的判断能力展示，不是参数调优工具。参数越多，越容易把"判断错了"变成"参数没调好"。
所以所有阈值都是**引擎内置常量 + Agent 自适应**，界面上只读展示，不给改。

## 2. 弹窗结构（七块，只有一处可交互）

1. **状态头**：`自动做T` + `Agent 运行中`（或 已收盘 / 已暂停）+ 最小化 / 关闭；**没有总开关**。
2. **结果条（只读）**：今日轮次、今日做T收益、累计收益、有效成本降幅。
3. **持仓表**：标的 / 底仓·可卖 / 账面成本 / **有效成本** / **Agent 今日判断** / 结果 / **做T开关（唯一交互）**。
4. **Agent 判断详情**（选中行展开）：观察 / 推理 / 结论三行 + 依据指标 + 失效条件。
5. **今日流水**：T·计划 → T·买入 → T·卖出 → T·结算（或 T·失败 / 强制回补）。
6. **未做T说明**：列出今天没做的标的及原因（价差不足 / T+1 可卖 0 / 停牌 / 持有不足 5 天）。
7. **策略口径（只读，折叠）**：`单轮 ≤ 底仓 20% · 最小价差 0.8% · 每日 1 轮 · 最晚 14:50 · 净持仓必须不变`
   —— 标注「由 Agent 与引擎决定，无需手动设置」。

## 3. 持仓表字段

| 列 | 内容 | 归属 |
| --- | --- | --- |
| 标的 | 名称 + 代码 | 展示 |
| 底仓 / 可卖 | `8 743 / 8 743` | 展示（T+1 直接影响能否做T） |
| 账面成本 | 买入均价 | 展示 |
| 有效成本 | `账面成本 − 累计做T净收益 ÷ 持仓` | 展示（做T成果的核心指标） |
| Agent 今日判断 | `正T 15.20↔15.45 · 500 股` / `不做：价差 0.42%` / `跳过：可卖 0` | Agent |
| 结果 | 已完成 +112.30 / 待触发 / — | 引擎 |
| 做T | 开关 | **HUMAN** |

## 4. Agent 判断详情（与棱镜报告同一套三要素）

选中一行后展开，用棱镜既有的「观察 / 推理 / 结论」结构，不新造格式：

```
观察：ATR14 0.31；20 日低 14.98；MA20 15.36；持仓成本 18.21；浮亏 −15.2%
推理：波动足以覆盖双边费用；15.20 贴近 20 日低有支撑，15.45 靠近 MA20 压力；
      正T 不动净持仓，适合中长期底仓
结论：做正T 500 股，价差 1.64%，预计净收益 112.30；跌破 15.05 或 14:50 未完成则放弃
```

- 三行都是**当天这次判断**的原文，不从别处拼；
- 缺指标就写 `—` 并给一句原因（如「ATR 缺 14 日样本」），不补 0；
- 不做T时同样给三行：`观察 → 推理 → 结论：本轮不做`。

## 5. 结果展示

| 指标 | 定义 | 缺数据时 |
| --- | --- | --- |
| 今日做T收益 | Σ 当日完成轮次净收益（含双边费用） | `—`（无完成轮次） |
| 累计做T收益 | `profitPool` 累计 | `—`（从未完成） |
| 有效成本降幅 | `profitPool ÷ 当前市值` | `—`（无持仓） |
| 成功率 | 净收益 > 0 的轮次 ÷ 完成轮次，附 `n=` | `—（样本 0）`，不写 0% |

## 6. 与主决策流的贴合

- T 计划在同一次分析 run 生成，**不进** `decision.orders`，不占「挂单」；
- 决策流新增 `T` 徽标（计划 / 买入 / 卖出 / 结算 / 失败），筛选栏可只看 T；
- 主决策要减仓该标的 → 先撤销未成交 T 腿并留痕；
- T 未完成 → 当日该标的禁止新开仓；
- 回撤闸门触发 / 触及 −20% 止损（按买入均价）→ 当日 T 暂停；
- 账本 degraded → 自动做T 暂停（不是用户关的，状态头显示「已暂停：账本异常」）。

## 7. 开关语义（唯一交互）

- 每行一个开关，切换即生效；关闭时若有未成交 T 腿 → 二次确认「关闭将撤销未成交的 T 腿」；
- 关闭只影响该标的，不影响其他持仓；
- 状态持久化在 `settings.autoT.positions[secid].enabled`；
- 首次使用默认全关；打开某只后从**下一个交易日**开始生成计划（当天已过 09:25 则次日生效）。

## 8. 界面原型

`docs/prototype/prism-autot-modal.html`：
浮层卡片覆盖在棱镜原页面之上，背景压暗；卡片内只有持仓表最后一列是可点的开关，
其余（结果条、判断详情、流水、策略口径）都是只读展示。
