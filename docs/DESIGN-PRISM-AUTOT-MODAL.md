# 设计稿 v5：棱镜「自动做T」弹窗（统计只留顶部；T 单并入主挂单管线）

> 状态：**仅设计，未实现**。相对 v4：① 删掉表底「合计」行（与顶部 chips 重复）；② T 单**并入主决策挂单与撮合管线**，不再单独造一套成交逻辑。

## 0. 一句话

弹窗只保留顶部五个统计 chip；做T 的条件单作为**主挂单**的一部分进入 `orders`，与普通买卖共用撮合、费用、T+1 与风控；
主决策每轮都能看到并撤销 T 单，行情恶化时可直接转为减仓/止损。

## 1. 尺寸与结构

| 条件 | 行为 |
| --- | --- |
| ≥1200px | 弹窗 920px，居中，两栏 |
| 860–1200px | `min(920px, 100vw − 32px)`，两栏 |
| <860px | 单栏，隐藏「账面成本 / 结果」列 |
| <560px | 全屏 sheet，chip 2×3 |

结构：状态头 → **5 个统计 chip（唯一的汇总口径）** → 持仓表（单只统计在名称下方）→ 两栏（Agent 判断 / 今日流水）。
**不再有**表底合计行、策略口径、主决策联动说明、设计稿页脚。

## 2. 统计口径

顶部 chips：今日轮次、今日做T收益、累计做T次数、累计做T收益、做T胜率（`n=`）。

- **完成轮次**：两腿都成交且净持仓复原；只成交一腿或强制回补失败不计入次数，标「未完成」。
- 单只统计（名称下方）：`做T N 次 · +X · 胜率 Y%`；未开启做T不显示；缺数据 `0 次 · — · —（n=0）`。
- 合计只在 chips 出现一次，表格不再重复。

## 3. T 单并入主挂单管线（本版重点）

### 3.1 落单方式

T 计划通过校验后，与普通委托写进**同一个 `orders` 文件**，字段增量：

```ts
{
  ...PrismOrder,
  channel: 'autoT',          // 主决策委托缺省 'main'
  tPlanId: 'T-20261125-601872',
  leg: 'open' | 'close',     // 第一腿 / 回补腿
  pairId: '...',             // 同一轮 T 的两腿配对
  expireAt: 1795...          // 14:50 截止（普通委托仍是次日失效）
}
```

- 撮合走**同一个 `matchTick`**：同样的分时量能、参与率、整手、涨跌停、T+1、费用模型；
- 成交写同一 `fills`（带 `channel:'autoT'`），`order.fee` 累加规则不变；
- 「挂单」计数**包含** T 单（用户要求并入），决策流里 T 单带 `T` 徽标，可与主委托区分。

### 3.2 与主决策的关系

| 场景 | 行为 |
| --- | --- |
| 每轮主决策 | 上下文包含「当前 T 挂单与已成交腿」；模型可显式撤销某笔 T 单 |
| 主决策要减仓同一标的 | 引擎先撤销未成交 T 腿，再执行减仓；已成交的 open 腿并入减仓数量一起处理 |
| 止损/回撤闸门触发 | 立即撤销全部 T 挂单；若 open 腿已成交，优先用 close 腿回补，回补后按主决策减仓 |
| 14:50 截止 | 未成交 T 单自动撤销；已成交一腿的，挂 close 腿强制回补（`forced`） |
| 收盘 | 校验净持仓与开盘一致；不一致记 `forced-fail`，次日首轮优先处理 |

### 3.3 风控豁免与保留

| 约束 | T 单 | 原因 |
| --- | --- | --- |
| 单票/行业/总仓上限 | **豁免**（净持仓不变） | 否则接近 30% 上限的持仓永远无法做T |
| 现金（买入腿） | 保留 | 真金白银占用 |
| 可卖数量（卖出腿） | 保留 | T+1 硬约束 |
| 涨跌停/停牌/价格偏离 | 保留 | 防错价 |
| 单笔金额上限 | 豁免 | T 是配对交易，按单腿计会误杀 |
| 回撤闸门 | 保留且优先 | 触发即暂停并撤单 |

### 3.4 这样做的收益

- 只有一套撮合与费用逻辑，不再维护第二套成交通道；
- T 单出现在主挂单列表，主决策天然获得干预机会；
- 三账本的一次写（`saveAll`）继续覆盖 T 的成交与净值，不需要第四本账；
- 只需新增 `prism-autot.json` 存**计划与轮次统计**（不做成交记账）。

## 4. 交互

- 唯一人工操作：每行做T 开关；关闭时撤销该标的未成交 T 腿（二次确认）；
- 弹窗打开/关闭不影响原页面与轮询；最小化后为右下角胶囊。

## 5. 验收

1. 1440×900 / 1280×800 / 1024×768 打开无横纵滚动条；
2. 顶部 5 个 chip 与单只统计数值一致，页面无第二处「合计」；
3. T 挂单出现在主挂单列表（带 T 徽标），普通挂单计数包含它；
4. 主决策减仓/止损/闸门触发时，T 挂单被撤销且留痕；
5. 收盘净持仓与开盘一致，`forced-fail` 为 0。
