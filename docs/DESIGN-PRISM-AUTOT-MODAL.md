# 设计稿 v3：棱镜「自动做T」弹窗（自适应尺寸，无默认滚动条）

> 状态：**仅设计，未实现**。本版在 v2「人类只开关、其余全展示」基础上，只改**尺寸自适应**与**删减底部注释**。
> 原型：`docs/prototype/prism-autot-modal.html`。

## 0. 一句话

弹窗打开即完整可见：宽度随窗口收缩、内容按两栏排布，**默认不出现横向或纵向滚动条**；
底部不再放「策略口径 / 主决策联动 / 设计稿说明」等注释。

## 1. 尺寸规则（自适应）

| 条件 | 行为 |
| --- | --- |
| 宽度 ≥ 1200px | 弹窗 920px 宽，右侧对齐工具条 |
| 860–1200px | 弹窗 `min(920px, calc(100vw − 32px))`，保持两栏 |
| < 860px | 弹窗变单栏，宽度 `calc(100vw − 24px)`；表格隐藏「账面成本 / 结果」两列 |
| < 560px | 全屏 sheet；判断详情默认折叠为一行，点击展开 |
| 高度 < 700px | 判断详情与流水改为左右两栏（本就默认两栏），不再叠加纵向高度 |

- 内容总高按 620px 设计（标题 56 + 结果条 56 + 表格 4 行 172 + 详情/流水 300 + 内边距）；
- `max-height: calc(100vh − 48px)` 只作为极端兜底，正常视口不会触发；
- 表格列宽用 `minmax` 与 `white-space: normal`，长文本换行而不是撑出横向滚动。

## 2. 结构（删减后）

1. 状态头：`自动做T` + `Agent 运行中` + 最小化 / 关闭；
2. 结果条：今日轮次、今日做T收益、累计收益、有效成本降幅；
3. 持仓表：标的 / 底仓·可卖 / 账面成本 / 有效成本 / Agent 今日判断 / 结果 / **做T 开关**；
4. 两栏区（宽屏并排、窄屏上下）：
   - 左：Agent 判断（观察 / 推理 / 结论 + 方向·买卖价·价差三格）；
   - 右：今日流水（T·买入 / T·卖出 / T·结算 / 强制回补）。

**已删除**（按本次要求）：
- 「策略口径（Agent 与引擎决定）」折叠块；
- 「主决策若要对同一标的减仓…」注释；
- 「做T 是唯一可操作项…」提示行；
- 「设计稿 · 示例数据」页脚。

> 这些信息保留在**设计文档**里，不进入运行时界面。

## 3. 交互不变

- 唯一可操作项：每行末尾的做T 开关；
- 关闭时若有未成交 T 腿 → 二次确认撤销；
- 弹窗打开/关闭不影响棱镜原页面与轮询；
- 最小化后为右下角胶囊。

## 4. 验收（视觉）

1. 1440×900、1280×800、1024×768 三档打开即完整显示，无横/纵滚动条；
2. 768 宽时表格不横向滚动，判断列换行显示；
3. 520 宽时全屏 sheet 可用，开关仍可点；
4. 页面内无任何脚注/说明文案。
