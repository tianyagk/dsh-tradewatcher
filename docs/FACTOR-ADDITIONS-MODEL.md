### 1.2 六条硬事实（写公式时不能忘）

1. **日K没有成交额字段**。`DayBar` 只有 `vol`（手）。`ADV20` 与任何"成交额"都必须用 `V×100×C` 还原，并标 `unitNote:'vol×close×100'`；缓存里的 `unitNote`（量纲断层）必须原样带出。
2. **分时的点频不统一**。同日同池实测 238 点（1 分钟）、272 点、176 点、102 点都有。任何"按点数"的因子（振幅、VWAP 样本数、量能节奏）都必须**按时间戳和累计成交额**算，不能按点数。
3. **分时的 `vol` 单位不统一**。实测：`0.000636` 的 `amount/(vol×price)≈100`（例：78,831,416 ÷ (29,196×27.01) ≈ 99.96）⇒ `vol` 是**手**（1 手=100 股）；`1.600519` 全天 48 根 5 分钟 `vol` 合计 3,240,848，与"股"量级一致 ⇒ `vol` 是**股**，且 `amount` 为 `null`。**没有量纲标定就没有 VWAP/RVOL**（见 §4.3 的 `lot` 规则）。
4. **没有盘口、没有 IOPV、没有历史净值、没有历史 PE/PB、没有个股历史资金流**。任何需要这些的量（价差、折溢价、估值分位、主力净流入历史）都是**伪因子**（§6）。
5. **板块没有日线源**。行业指数/板块指数拿不到历史 K 线 ⇒ "20 日相对行业中位"不可算；只有"当日个股 − 当日板块涨幅"可算。
6. **广度/涨跌停没有历史**。`breadth.json` 只有 2 天，`market-extras.json` 不存在 ⇒ 任何"广度分位/涨跌停分位"现在返回 `null`，不是 0、不是 50。

### 1.3 三类资产差异（决定因子能不能算）

| 维度 | 股票 | ETF | 指数 |
|---|---|---|---|
| 复权 | fq=1 | fq=1 | **fq 恒 0** |
| 最小变动 | 0.01 元 | 0.001 元 | 无（不可交易） |
| 涨跌幅限制 | 主板 10% / 双创 20% / 北交 30% / ST 5% | 主板/跨境/债/商品 10%；创业板/科创板 ETF 20%；**以 `f47/f48` 为准** | 无 |
| 交割 | T+1 | 股票 ETF T+1；债券/黄金/跨境/货币/商品 ETF **T+0** | — |
| 特有 | ST/停牌/股本变动 | **份额申赎**、折溢价、外盘时段 | 只能做环境，不能选股/下单 |

## 2. 评判方法：四道门

新增因子必须同时过四道门，缺一不补：

| 门 | 问题 | 判据 | 不过的例子 |
|---|---|---|---|
| **G1 有真值** | 数据是"现在能观测到的真值"吗？ | 不是回填、不是插值、不是用当前值反推历史 | 历史 PE/PB 分位（无历史）、ETF 折溢价（无 IOPV） |
| **G2 有含义** | 能用一句话说清"它回答什么问题"？ | 回答的是**状态**（能不能做、风险多大），不是"会不会涨" | 对全池扫最优相关得到的"因子" |
| **G3 有增量** | 与现有因子的横截面 \|ρ\| 是否 < **0.7**？ | 或能改变一个**决策边界**（不是只换个说法） | `RV20`（ρ=0.952）、`AMIHUD`（ρ=0.989）、`EXCESS20`（排序等价） |
| **G4 可复算** | 公式、窗口、单位、PIT、缺失是否写死？ | 任一输入缺失 ⇒ `null` + 原因，不用 0/50/均值顶替 | "综合情绪分"（权重拍脑袋） |

> **G3 的 0.7 是工程阈值，不是统计定论**：它只用来挡"明显重复"，不替代样本外验证。过门不等于有效，只等于"值得进因子表和影子日志"。

## 4. 因子卡（公式可复算）

### 4.1 波动率状态

#### F1 `VOL.ONSHARE20` — 隔夜波动占比（**先补**）

**回答的问题**：这只标的的波动，主要发生在**隔夜**还是**日内**？（决定"做T有没有肉"和"过夜风险多大"）

```
r_on,t  = ln(O_t / C_{t−1})                    // 隔夜（含集合竞价）
r_id,t  = ln(C_t / O_t)                         // 日内
r_cl,t  = ln(C_t / C_{t−1}) = r_on,t + r_id,t   // 全日

Var_on   = (1/20) Σ (r_on,t − mean_on)²
Var_id   = (1/20) Σ (r_id,t − mean_id)²
Var_cl   = (1/20) Σ (r_cl,t − mean_cl)²
Cov_oi   = (1/20) Σ (r_on,t − mean_on)(r_id,t − mean_id)

ONSHARE20 = 100 × (Var_on + Cov_oi) / Var_cl
          = 100 × Cov(r_on, r_cl) / Var(r_cl)     // 隔夜对全日方差的贡献份额（恒等）
```

> 为什么不用 `Var_on/(Var_on+Var_id)`：它忽略协方差项。实测 `2·Cov_oi/Var_cl` 的中位为 **−5.2%**、p10 **−44.8%**、p90 **+12.6%**，忽略它会把个别标的的占比算偏 10 个百分点以上（如工商银行：粗算 18.8%、贡献口径 5.3%）。
>
> **可复算恒等式**：`Var_on + Var_id + 2·Cov_oi = Var_cl` ⇒ 隔夜贡献 + 日内贡献 ≡ 100%。单测可直接断言两边相加为 100（±1e-9）。
>
> **与同批 `FACTOR-ADDITIONS-BACKTEST` 的差异**：该文档写的是粗分解 `100×Var_on/(Var_on+Var_id)`（未扣协方差；其实测 ρ≈−0.09、7 只区间 18.8%–46.9%）；本文以**贡献口径**为准。两者不是同一个数（工商银行：粗 18.8% vs 贡献 5.3%），**不可混比**；若实现只做粗分解，字段必须标 `variant:'gross'`，且文案不写"方差占比"。

| 项 | 规定 |
|---|---|
| 窗口 | 20 根**已完成**日K，需 **21 根**（`r_on` 要用 `C_{t−1}`） |
| 数据源 | 日K（fq=1 的 O/H/L/C） |
| 单位 | %（0–100） |
| 缺失 | `<21` 根 ⇒ `null`「日K不足21根」；`Var_cl=0` ⇒ `null`「20日零方差」；20 日内一字板日 ≥3 ⇒ `null`「一字板样本占比过高」（方差分解退化）；贡献值 <0 或 >100 ⇒ 夹到 [0,100] 并标 `clamped=true`，若 20 日内 >20% 的日子被夹 ⇒ `null`「分解不稳定」 |
| 复杂度 | O(20)，纯算术；单标的 < 0.01 ms |
| 消费者 | **主**（隔夜风险/是否持仓过夜）+ **T**（日内波动占比低 ⇒ 档距再大也赚不到） |
| 不能用于 | ① 方向预测；② 波动**水平**（它是占比，不是幅度）；③ 跨资产直接比较——跨境/黄金 ETF 的"隔夜"含外盘时段（实测黄金ETF 518880 = **76.4%**，工商银行 = 5.3%，两者不可同读）；④ 单日值（20 日统计量） |

**实测（2026-11-26，20 日，贡献口径）**：p10 **1.7%** / 中位 **16.4%** / p90 **40.6%**（n=48；min −10.5、max 76.4）；与 ATR14 ρ=**−0.123**、与 20 日收益 ρ=−0.237、与 `ATR/AMP` 比 ρ=0.475（不是同一个数）。 粗口径（`Var_on/(Var_on+Var_id)`，供与 BACKTEST 对照）：p10 6.4% / 中位 19.5% / p90 41.7%；7 只 18.8%–46.9%。

**做T 读法（示例，不是门槛）**：ATR 2.44% 的黄金ETF 隔夜贡献 **76.4%** ⇒ 日内可捕获的波动只占方差的约四分之一，"ATR 够大"不等于"日内有肉"；同样 ATR 4.65% 的招商轮船隔夜贡献 45.0%。**这两个数放在一起，才能回答"该不该对它开网格"。**

#### F2 `VOL.VOLCHG` — 5/60 日波动比（**排队 #1**）

**回答的问题**：最近一周的波动，比过去三个月**放大还是收缩**？

```
TR_t = max(H_t−L_t, |H_t−C_{t−1}|, |L_t−C_{t−1}|)
ATRn% = (1/n) Σ_{i=t−n+1..t} TR_i / C_t × 100
VOLCHG = ATR5% / ATR60%
```

| 项 | 规定 |
|---|---|
| 窗口 | `ATR5` 用 5 根 TR、`ATR60` 用 60 根 TR（同一 TR 定义）；需 **61 根** |
| 数据源 | 日K |
| 单位 | ratio（1.00 = 与三个月前同水平） |
| 缺失 | `<61` 根 ⇒ `null`；`ATR60%=0` ⇒ `null` |
| 复杂度 | O(60)；可增量化到 O(1)（滚动和） |
| 消费者 | 主（波动扩张/收缩）+ T（扩张期开网格、收缩期收手） |
| 不能用于 | ① 推"继续扩张"（波动聚集是统计倾向，不是承诺）；② 跨标的比较（它是自比）；③ 替代 `ATRRANK120`（后者是水平分位，前者是**变化**）；④ 单独当"波动信号"——实测与 20 日收益 ρ=**+0.533**，上涨本身会推高近期波动，必须与 `RET20` 同屏读 |

**实测**：p10 **0.60** / 中位 **0.97** / p90 **1.36**；与 ATR ρ=−0.253，与 `ATRRANK120` ρ=**0.539**（有重叠但不等价），与 20 日收益 ρ=+0.533。

#### F3 `VOL.DOWNSHARE20` — 下行波动占比（**不补，仅给公式**）


**实测**：p10 30.1% / 中位 **60.0%** / p90 74.3%；与 ATR ρ=0.151（看着正交），但**与 20 日收益 ρ=−0.819** —— 它主要是"最近跌了"的另一种写法，不是独立的"风险不对称"。**结论：不单列**；若要做下行风险，应改为"对收益回归后的残差下行占比"，那需要更长样本与回归，当前数据不支持。

### 4.2 流动性

#### F5 `LIQ.RVOL` — 成交额节奏（**先补**）

**回答的问题**：**今天**的量能，相对它自己平时，是放量还是缩量？（ADV20/FILL 是 20 日平均假设，回答不了"今天"）

```
A_cum(t) = Σ_{i: 09:30 < τ_i ≤ t} A_i                      // 分时点成交额（元），逐点增量求和
f(t)     = PROFILE[assetClass][elapsedTradingMinutes(t)]    // 12 日实测中位，带版本号
RVOL(t)  = (A_cum(t) / ADV20) / f(t)
ADV20    = (1/20) Σ_{i=t−19..t} V_i × 100 × C_i              // 与 LIQ.ADV20 同口径
```

**实测时间剖面 f(t)**（12 个稠密日、A股/ETF、每日中位后再跨日中位）：

| 时刻 | 09:45 | 10:00 | 10:30 | 11:00 | 11:30 | 13:30 | 14:00 | 14:30 | 14:50 |
|---|---|---|---|---|---|---|---|---|---|
| f(t) 中位 | 0.183 | 0.275 | 0.407 | 0.495 | 0.583 | 0.707 | 0.786 | 0.877 | 0.953 |
| 跨日 p10–p90 | 0.166–0.220 | 0.251–0.349 | 0.374–0.513 | 0.451–0.597 | 0.555–0.681 | 0.669–0.759 | 0.758–0.828 | 0.857–0.906 | 0.948–0.960 |

> 剖面很稳定（跨日 ±3–5 个百分点），所以 `f(t)` 可以用"池中位 × ≥10 个交易日"标定；**必须写 `profileVersion` 与 `sampleDays`**，禁止把单日剖面写死。

| 项 | 规定 |
|---|---|
| 窗口 | 当日 09:30–t；要求 `t ≥ 09:45`、有效点 ≥30、`ADV20` 有效 |
| 数据源 | **优先**：实时行情累计 `amount`（O(1)）；**回退**：分时逐点 `amount`（O(k)）+ 日K `vol/close` |
| 单位 | ratio（1.00 = 与平时同节奏） |
| 缺失 | 无 `amount` 且无 `avg` ⇒ `null`「分时无成交额」；可用 `avg×V×lot` 反推成交额时标 `amountApprox=true`（**不得当精确值**）；`vol` 量纲标定失败 ⇒ `null`「量纲未标定」；`ADV20=null` ⇒ `null`；半日市/停牌 ⇒ `null`；`t<09:45` ⇒ `null`「开盘样本不足」 |
| 复杂度 | O(1)（行情累计）/ O(k)（回退分时，增量维护 `A_cum`）；缓存 60s |
| 消费者 | 主（"今天有没有量"）+ T（G7/FILL 的当日修正）+ 执行（拆单节奏） |
| 不能用于 | ① 当方向信号（放量可以涨也可以跌）；② 跨市场（港股/美股 `vol` 单位不同，实测 `116.*` 的 amount/ADV≈0.007，直接算会错 100 倍）；③ 用"当日总量 ÷ ADV20"代替（少了时间归一，10:00 会恒等于 0.27）；④ 把 RVOL 高当"资金流入"（只是成交活跃，没有买卖方向） |

**实测（2026-11-26 14:30，34 只 A股/ETF：≥150 点且 amount/ADV 可用）**：RVOL 中位 **0.70**（当日全池成交额约为 20 日均额的 0.7 倍），p10 **0.38**、p90 **1.04**。**读法**：0.70 是"缩量日"，不是"没人交易"；分位需要 ≥20 日历史才能给。

#### F6 `LIQ.TURN1` — 当日换手率（**仅展示，已有**）

`TURN1 = quote.turnover (f8)`，单位 %，盘中 10s。**只能当日**：历史流通股本/流通市值没有，回填 20 日均换手是伪因子（§6 P1）。ETF 尤其不可（份额每日申赎变化）。

#### F7 `LIQ.AMIHUD` — 非流动性（**不补**）

```
ILLIQ20 = (1/20) Σ |r_t| / A_t × 1e9        // A_t = V_t×100×C_t
```

**实测**：与 `ATR14% ÷ (ADV20/1e8)` 的合成值 ρ=**0.989**。**结论：不补**——它几乎就是"波动 ÷ 成交额"的另一种写法，而这两个量已经在表里；且日K无成交额，`A_t` 本身是二次近似。

### 4.3 价格结构（含日内）

#### F8 `INT.VWAPDEV` — 日内 VWAP 偏离（**先补 #1**）

**回答的问题**：现价相对**今天所有成交的平均价**，贵了还是便宜了？（做T 的唯一实时锚）

```
lot      = median_i( A_i / (V_i × P_i) )          // 量纲标定
           ∈ [0.5, 1.5]  ⇒ vol 是"股"
           ∈ [50, 150]   ⇒ vol 是"手"（×100）
           其它          ⇒ 量纲未标定，整条 null
VWAP_t   = Σ_{i≤t} A_i / (Σ_{i≤t} V_i × lot)
VWAPDEV  = (P − VWAP_t) / VWAP_t × 100
```

| 项 | 规定 |
|---|---|
| 窗口 | 当日 09:30–t；有效点 ≥**30**；首点 ≤**09:35**（否则 `null`「分时起点过晚」） |
| 数据源 | **优先**：实时行情累计 `amount/vol`（O(1) 一次除法）；**回退**：分时 `points[t,price,avg,vol,amount]`（O(k)）+ 实时 `P` |
| 单位 | % |
| 缺失 | 无分时且行情无累计 `amount/vol` ⇒ `null`；无 `amount` 且无 `avg` ⇒ `null`「无成交额且无均价」；`lot` 不在区间 ⇒ `null`「量纲未标定」；点数 <30 ⇒ `null`；`lkg` 报价 ⇒ `null`（SPEC §5.6）；行情 `amount/vol` 是否为累计值未标定 ⇒ 不得当累计用（先与分时累计对拍，差 >0.5% 即 `null`） |
| 近似 | 分时自带 `avg`（东财 f58 的累计均价）时直接 `VWAP=avg`，跳过 `lot` 标定（`avgApprox=false`）；只有 `(H+L+C)/3` 近似时必须 `avgApprox=true`，且**不可与真值混比** |
| 复杂度 | O(1)（行情累计值）/ O(k)（回退分时，k≤240）；单标的每 10s 更新一次 < 0.01 ms |
| 消费者 | **T**（SPEC §4.3 的买/卖腿触发就是以 VWAP 为中心：`P ≤ VWAP×(1−0.8s/100)`）+ 主（"现价 vs 今日均价"） |
| 不能用于 | ① 当"公允价/估值"；② 跨日累计（VWAP 是当日累计，隔日必须重置）；③ 指数下单（指数不可交易，只作环境）；④ 把 `(H+L+C)/3` 当精确 VWAP；⑤ 把 5 分钟点当 1 分钟点（样本数按时间戳，不按点数） |

**实测（2026-11-26，A股/ETF 37 只）**：14:00 的 VWAPDEV p10 **−1.96%** / 中位 **−1.13%** / p90 **+0.75%**（当日为下跌日，中位偏负是正常的）；点数 238 为主，覆盖不足的标的（如 600519 只有 48 个 5 分钟点且无 `amount`）必须 `null`。

> **衔接提示**：`FACTOR-SPEC §4.1 T7` 已定义 `INT.VWAPDEV`，但当前 `src/host/prismRoutes.ts` 没有任何 VWAP 计算（grep 无 `vwap`）。**这不是"新增口径"，是"补一个已批准但未实现的因子"**——优先级最高。

#### F9 `INT.POSDAY` — 日内区间位置（**先补，与 F8 同批**）

**回答的问题**：现价在**今天**的最高—最低区间里的哪个位置？（入场/出场的位置感）

```
POSDAY = (P − L_day) / (H_day − L_day) × 100
```

| 项 | 规定 |
|---|---|
| 窗口 | 当日 09:30–t；`H_day/L_day` 取**实时行情**（不是昨日、不是日K） |
| 数据源 | 实时行情 `high/low/price` |
| 单位 | 0–100 |
| 缺失 | `H_day=L_day` ⇒ `null`「一字/无区间」；09:40 前 ⇒ `null`「区间未成形」（或带 `early=true`，二选一，写死） |
| 复杂度 | O(1)（行情里已有 H/L） |
| 消费者 | T（"买在区间低位/卖在区间高位"的位置判断）+ 主（日内位置） |
| 不能用于 | ① 当"强弱/超买超卖"（低位可以更弱）；② 用昨日区间顶替；③ 用收盘后的 `(C−L)/(H−L)` 冒充盘中值（那是 `POS.CLV`，盘中不可得） |

**实测（2026-11-26 收盘，A股/ETF 37 只）**：POSDAY 中位 **39.8**；与 `VWAPDEV` 的 ρ=**−0.239** ⇒ 两者**不是同一个数**（一个是成交量加权均价，一个是价格区间），可以同批上线。

#### F10 `POS.GAP20` — 缺口频率与回补率（**排队**）

```
GAP_t     = O_t / C_{t−1} − 1
GAPFREQ20 = 100 × #{|GAP_t| ≥ 1%} / 20
GAPFILL20 = 100 × #{当日回补} / #{|GAP_t| ≥ 1%}
  GAP>0 且 L_t ≤ C_{t−1}  ⇒ 回补
  GAP<0 且 H_t ≥ C_{t−1}  ⇒ 回补
```

| 项 | 规定 |
|---|---|
| 窗口 | 20 根已完成日K（需 21 根）；阈值 1%（0.5% 太常见：实测中位 65% 的日子都有） |
| 单位 | % |
| 缺失 | `<21` 根 ⇒ `null`；20 日内无 ≥1% 缺口 ⇒ `GAPFILL20=null`「无样本」，`GAPFREQ20` 仍可给 |
| 复杂度 | O(20) |
| 消费者 | 主（"缺口回补的历史基数"）+ T（跳空日暂停常规网格的 flag） |
| 不能用于 | ① "缺口必补"；② 当概率预测（20 日样本、无分层、无显著性）；③ 跨境 ETF 的溢价跳空（不是技术缺口） |

**实测**：`GAPFREQ20` p10 **0** / 中位 **40%** / p90 **75%**；`GAPFILL20` p10 25.0% / 中位 **58.3%** / p90 87.5%（n=42）；与 ATR ρ=0.774（频率主要是波动的影子），回补率与 ATR ρ=0.278（有一点独立信息，但样本太薄）。

#### F11 `POS.DISTATR20` — 距支撑/压力（ATR 倍数）（**排队**）

```
ATR14_abs = ATR14% / 100 × P
DISTHI    = (max(H_{20}) − P) / ATR14_abs      // 距 20 日高点的 ATR 倍数
DISTLO    = (P − min(L_{20})) / ATR14_abs      // 距 20 日低点的 ATR 倍数
```

| 项 | 规定 |
|---|---|
| 窗口 | 20 根已完成日K + ATR14；**`P` 为盘中值时，20 根窗口不含今日**（否则拿今日自己的 H/L 与 P 比，会系统性得到"距高点 0 ATR"）；`P` 为收盘价时可用含今日的 20 根，但必须全表同一口径 |
| 单位 | ATR 倍数（无量纲） |
| 缺失 | `<21` 根或 `ATR14_abs=0` ⇒ `null` |
| 复杂度 | O(20) |
| 消费者 | 主（"距压力还有几倍 ATR"）+ T（失效位/止损宽度） |
| 不能用于 | ① 当"支撑一定有效"；② 与 `POS.PCT20` 同时用（实测 ρ=−0.765，信息重叠）；③ 复权/不复权混算（H/L 与 ATR 必须同一 fq） |

**实测**：`DISTHI` p10 0.81 / 中位 **4.26** / p90 6.18；`DISTLO` p10 0.04 / 中位 **0.79** / p90 3.54。**读法**：中位标的距 20 日低点不到 1 个 ATR——"贴着支撑走"是常态，不是异常。

### 4.4 相对强弱

#### F12 `RS.EXCESS20` — 相对沪深300 的 20 日超额（**仅展示**）

```
EXCESS20 = (C_t/C_{t−20}−1)×100 − (B_t/B_{t−20}−1)×100      // B = 1.000300 收盘（fq=0）
```

**为什么它不是新信息**：同一天里 `B20` 对所有标的都是同一个常数 ⇒
`EXCESS20_i = RET20_i − B20` ⇒ **横截面排序与 `RET20` 完全一致**。它只把"跑赢/跑输"写成绝对数，减少模型自己做减法的错误。

| 项 | 规定 |
|---|---|
| 窗口 | 20 个交易日；基准与标的**按日期对齐**，缺任一端 ⇒ `null`「基准缺 20 日窗口」。**默认日频口径**：`C_t` 取最后一根已完成日K收盘；若主决策要盘中值，用 `P` 与基准实时点位替换分子，两者必须同一 `asOf`，否则 `null` |
| 单位 | % |
| 复杂度 | O(20) |
| 消费者 | 主（只作读法明确化）；T 无关 |
| 不能用于 | ① 当 alpha（未扣行业/风格/β）；② 当预测；③ ETF 的"跟踪指数超额"——用 300 只是**市场基准**，跨境/科创/债 ETF 会系统性偏离；④ 跨资产类别（债/金 vs 股）直接读成"强弱" |

**实测**：p10 **−19.2%** / 中位 **−6.0%** / p90 **+9.0%**（基准 20 日 −4.55%）。

> 如果一定要"相对强弱"，真正有增量的是**行业中性**（F13）或 **β 调整**；后者需要可信的 β，而实测 β 与 ATR ρ=0.75（见 F14），噪声大，**不建议**。

#### F14 `RS.BETA60` — 60 日 β（**仅展示**；SPEC 已有扩展）

```
β = Cov(r_i, r_b) / Var(r_b)      // 60 个日对数收益，按日期对齐
```

| 项 | 规定 |
|---|---|
| 窗口 | 60 个收益（需 61 根），对齐后 ≥40 对；`Var_b=0` ⇒ `null` |
| 单位 | ratio |
| 复杂度 | O(60) |
| 消费者 | 主（风险预算/仓位），不进 T |
| 不能用于 | ① 当"弹性预测"；② 60 日窗口跨风格切换会失真；③ 指数自身对 300（恒等于 1，直接 `null`）；④ 与 ATR 同时当两个独立风险量（ρ=0.75） |

**三条资产规则**：

1. **指数永远不进"可下单候选"**：`VWAPDEV/POSDAY` 对指数只写"环境参考"，`TICK/FILL/LIMITDIST` 恒 `null` + 「指数不可交易」；不许用 0 或均值顶替。
2. **ETF 的"基准"不是沪深300**：只有 5 个指数有日K口径（300 / 1000 / 科创50 / 中证2000（ETF 代理）/ 半导体 ETF），跨境/债/金 ETF 的跟踪指数拿不到 ⇒ `EXCESS20` 必须标 `benchKind:'market'`，不能写"超额收益"。
3. **股票与 ETF 的 `vol` 量纲可能不同**（手 vs 股）：任何 VWAP/RVOL 必须先过 `lot` 标定；标定失败就 `null`，**不许假定 100**。

**逐类说明**：

- **A股**：10 个个股/ETF 因子全部可算（`RS.SECTOR1` 需行业名），另有 5 个市场级因子（`ENV.*/SEN.*`）不按标的算。ST/停牌/一字板/涨跌停要按 `null` 或 `flag` 处理；`fq=1` 已把除权跳空消掉，但**停牌复牌**造成的缺口仍是真缺口，`GAP20` 会把它算进去（需在 `quality` 标 `suspensionGap=true`）。
- **ETF**：日线类同股票；**份额申赎**使"历史换手/历史市值"不可算（§6 X5），`RVOL` 不受影响（分子分母都是元）；跨境/黄金 ETF 的 `ONSHARE20` 含外盘时段，**不能与 A 股股票横比**；T+0 品种（债券/黄金/跨境/货币/商品）可做日内，但其 `RS.EXCESS20` 只能是"相对股市"，不是"跟踪指数超额"；无 IOPV/净值 ⇒ 折溢价不可算。
- **指数**：只能算趋势/波动/位置 + `ONSHARE20/VOLCHG`；无成交额 ⇒ `RVOL/ADV/FILL` 恒 `null`；不可交易 ⇒ `TICK/LIMITDIST` 恒 `null` + 原因；`VWAPDEV/POSDAY` 可算但**只进环境段**，不得进候选池或下单；`RS.BETA60` 对 300 自身恒为 1，直接 `null`。

## 7. 三个最值得先补的因子

排序依据：**决策影响 × 可算性 × 增量 ÷ 成本**；三个都**不需要新数据源**。

### 7.1 第一：`INT.VWAPDEV`（+ `INT.POSDAY` 同批）

**为什么是它**

1. **它是 SPEC 已经批准、但代码里没有的因子**：`FACTOR-SPEC §4.1 T7` 定义了它，`§4.3` 的做T触发公式（`P ≤ VWAP×(1−0.8s/100)` / `P ≥ VWAP×(1+0.8s/100)`）**以 VWAP 为中心**。没有 VWAP，"触发价"只能拍脑袋——这是当前做T链条最硬的缺口。
2. **它是唯一"实时锚"**：现有 10 个因子全是日线/日频，最接近实时的只有 `MA20DEV`（用 `P` 替换分子），但那是"相对 20 天均线"，不是"相对今天的成交均价"。做T 需要"今天买贵了没有"，只有 VWAP 能回答。
3. **数据已在本地**：行情累计 `amount/vol` 可直接算（O(1)）；分时回退路径单日覆盖 37/40（A股/ETF 中有 `amount` 且 ≥100 点），但**跨 12 日全程只有约 22 只**——所以 VWAPDEV 是 live 因子，历史验证必须靠前向记录（≥120 个稠密日 / ≥20 只，见 FACTOR-VALIDATION 门）。
4. **实测有区分度**：14:00 的 `VWAPDEV` p10 **−1.96%** / 中位 **−1.13%** / p90 **+0.75%**；与 `POSDAY` 的 ρ 仅 −0.239 ⇒ 两个数不是重复。
5. **成本可控**：O(k) 一次扫描，`k≤240`；只对**持仓**（≤10 只）计算即可覆盖做T，自选不必每轮拉分时。

**必须先解决的数据问题**（否则不要上线）

- `vol` 量纲：`amount/(vol×P)` 必须落在 `[0.5,1.5]`（股）或 `[50,150]`（手），否则整条 `null`；实测 600519 的 5 分钟序列**没有 amount**，只能 `null`，不能猜。
- 点频：按时间戳取"≤t 的点"，不按点数；5 分钟序列的 30 点门槛要换算成"≥150 分钟"。
- 起点：首点晚于 09:35 ⇒ `null`（VWAP 已经有偏）。
- `lkg`：报价来自兜底库 ⇒ `null`（SPEC §5.6）。

**验收**：构造 3 天分时（1 分钟/5 分钟/无 amount），断言 `VWAPDEV` 分别为"可算/可算/`null`"；用 `ΣA/(ΣV×lot)` 手算对拍，误差 <0.01%。

---

### 7.2 第二：`VOL.ONSHARE20`

**为什么是它**

1. **它是唯一与 ATR 正交的波动维度**：与 ATR ρ=**−0.123**、与 20 日收益 ρ=−0.237；而所有"波动水平"候选（RV/Parkinson/AMP）与 ATR 的 ρ 都在 0.95 以上。
2. **它直接回答做T 的核心问题**："这只标的的波动，日内能做吗？"——ATR 2.44% 的黄金ETF 隔夜贡献 **76.4%**，意味着约四分之三的方差在收盘后发生，日内网格的"肉"只有约四分之一；而 ATR 4.65% 的招商轮船隔夜贡献 45.0%。**同样的 ATR，完全不同的做T价值。**
3. **它也服务主决策**：隔夜占比高的持仓，"持仓过夜"的风险溢价更高；这是仓位/过夜决策的直接输入。
4. **零新数据、O(20)、可缺失规则简单**：21 根日K 即可；一字板/零方差有明确 `null` 规则。

**实测分布**：p10 **1.7%** / 中位 **16.4%** / p90 **40.6%**；7 只已启用做T + 黄金ETF 对照（8 只）的实测值：518880 **76.4%**、601872 45.0%、510300 44.4%、588000 25.5%、511090 23.5%、560010 18.7%、600900 14.1%、601398 5.3%。

**怎么用（先描述，不进闸）**

- 主决策行：`隔夜波动贡献 45.0%（20日）`；
- T 计划页：`日内波动贡献 55.0%`（=100−45.0）作为"档距是否值得"的旁注；
- **不进 `t-gate-v2`**：任何门槛化都要先有 ≥20 轮影子（FACTOR-VALIDATION 的 G3）。

**不能做什么**：不能推方向；不能当波动幅度；跨境/黄金 ETF 的隔夜含外盘时段，不能与 A 股股票横比；一字板样本要 `null`。

### 7.3 第三：`LIQ.RVOL`

**为什么是它**

1. **流动性四件套里唯一空白**：`ADV20` 管容量、`FILL` 管时间、`TURN1` 管当日热度、`AMIHUD` 已被证明与 ATR/ADV 合成 ρ=0.989（不补）；**"今天的量能相对平时"没有任何因子回答**。
2. **它修正 FILL 的乐观假设**：SPEC 的 `FILL = N/(ADV20×ρ/240)` 用的是 20 日均额（且 `ADV20/FILL` 目前尚未在代码落地）；如果今天只有平时的 0.70 倍（实测 2026-11-26 全池中位），真实填充时间要 ×1.43。RVOL 是把"历史平均"换成"今天"的唯一低成本办法。
3. **剖面已经实测稳定**：12 个稠密日的 f(t) 跨日 p10–p90 只有 ±3–5 个百分点（10:00 0.251–0.349、14:30 0.857–0.906），说明"时间归一"是可行的，不是拍脑袋。
4. **它服务主决策的"放量/缩量"叙事**：LLM 现在只能看到 `volRatio`（5/20 日量比，日频），看不到"今天盘中量能"。

**必须先解决的数据问题**

- `amount` 缺失（600519 类）⇒ `null`；`vol` 量纲不统一 ⇒ 先标定；
- `f(t)` 必须带 `profileVersion` + `sampleDays`（≥10 日），**禁止单日剖面写死**；
- 港股/美股不适用（实测 `116.*` 的 amount/ADV≈0.007，单位不同）。

**验收**：用 12 日归档重算 f(t)，与本文表格逐点差 <0.02；构造"半日市/停牌/无 amount"三种输入，必须分别 `null` + 原因。**进门槛的前提**：≥120 个稠密日 / ≥20 只 + 影子 A/B（与同批 BACKTEST 文档口径一致）；在此之前只记录，不判。

### 9.2 `FactorEnvelope` 的扩展字段（只增不改）

现有信封（SPEC §5.3）已含 `v/unit/asOf/dailyFinalAsOf/intradayAsOf/fq/window/stale/src/quality/missing`。新增因子需要**三个可选顶层字段 + `quality` 的四个键**：

```ts
interface FactorEnvelope<T> {
  // …既有字段不变…
  /** 相对强弱/商品映射的基准：secid + 名称 + 口径（market/tracking/index） */
  bench?: { secid: string; name: string; kind: 'market' | 'tracking' | 'index' } | null
  /** 日内因子的时间剖面版本与样本（RVOL 必带） */
  sessionProfile?: { version: string; sampleDays: number; assetClass: 'stock' | 'etf' } | null
  /** 历史深度（情绪类因子必带：本地有几天就写几天） */
  historyDepth?: { days: number; from: string | null; to: string | null } | null
  /** 量纲/近似说明（VWAP 的 lot、ADV 的 vol×close×100 等） */
  quality: {
    // …既有…
    lotCalibration?: 'shares' | 'lots' | null
    avgApprox?: boolean
    unitNote?: string | null
  }
}
```

**四条硬约束**：
1. `bench` 非空时，`missing` 必须说明基准是否对齐；基准缺 ⇒ `v=null`。
2. `sessionProfile` 只在 `INT.*` / `LIQ.RVOL` 出现；没有它，RVOL 不许发布。
3. `historyDepth.days < 20` ⇒ 分位类字段必须 `null` + 「样本不足」，**不许用 2 天算 60 日分位**。
4. 任何 `v=null` ⇒ `missing` 非空；任何 `v` 非空 ⇒ `missing=null`（沿用 SPEC V5）。

### 10.4 价差伪因子证据（复算）

```
日均振幅中位 AMP20 = 4.50%
一跳中位 tickPct   = 0.053%
倍数               = 4.50 / 0.053 ≈ 85×
Corwin–Schultz 估计（20 日均）：p10 = −2.483% / 中位 = −0.418% / p90 = +0.222%
50 只中 42 只的 20 日中位为负；47.4% 的单日为负
```

**结论**：在这批数据上，任何"用最高最低价估计价差"的做法都会产出负值或放大 85 倍的值；**价差不可算，只能等盘口数据**。
