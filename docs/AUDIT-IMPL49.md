# AUDIT-IMPL49 —— 交易日历：外部覆盖文件（每月手工更新）

**一行结论**：外部日历文件 `<DSH_HOME>/dsh-tradewatcher/trading-calendar.json` 已接入，优先级
**外部文件 > 内置假日表 > 周末规则**；**当月被覆盖就以文件为准**（缺键 = 未覆盖 ⇒ 面板/工具/归因三处可见告警
"交易日历未更新到本月"并退回内置表），文件非法（版本/格式/跨月/重复/坏 JSON）⇒ **改名隔离 + `.reason.txt` 留痕**
后退回内置；新增只读校验入口 `npm run calendar:check`。`npm run check` EXIT=0，**579/579 × 2 时区**。

---

## 1. 文件格式与位置

- **位置**：`~/.dsh/dsh-tradewatcher/trading-calendar.json`（用户状态目录，**不是仓库文件** ⇒ 升级不覆盖）。
- **格式（按月列休市日）**，真实样例（2026 年 10 月，来源：上交所〔2025〕45号公告）：

```json
{
  "v": 1,
  "source": "上交所 2026 年部分节假日休市安排（上证公告〔2025〕45号）",
  "updatedAt": "2026-10-08",
  "months": {
    "2026-10": ["2026-10-01", "2026-10-02", "2026-10-05", "2026-10-06", "2026-10-07"],
    "2026-11": []
  }
}
```

- **为什么列休市日而不是列交易日**：一个月里**法定休市只有 0–5 天**，交易日有 18–23 天（差 4–5 倍）。
  休市日是"从公告抄下来的例外"，交易日是"整月枚举" —— 前者写得更少、更不容易抄错，而且**周末不必写**
  （周末由 `shWeekdayOf` 判定，写进去只会重复）。
- **`"2026-11": []` 的语义**：本月无法定休市但**已被覆盖**（空数组 ≠ 缺键）。缺键 ⇒ 未覆盖 ⇒ 告警 + 退回内置表。

## 2. 优先级与失败方向（写进代码注释）

`rescue.ts:640 tradingDayState` → `tradingCalendar.monthCoveredByFile(月)`：

| 情形 | 判定 |
|---|---|
| 文件覆盖当月 | **以文件为准**：文件列了 ⇒ 休市（`label` = 「外部日历（手工维护）」）；文件没列 ⇒ 交易日（**内置表不参与**，用户可用"不写"纠正过期的内置条目） |
| 未覆盖当月 / 文件缺失 / 文件非法 | 退回**内置假日表**（2026 法定休市，`rescue.ts:599`） |
| 内置表也没命中 | 按**交易日**处理 ⇒ 失败方向 = **多采一天**，不会把真交易日误判成休市（漏采真实信号更糟） |
| 周末 | 先于两者判定（`dow === 0/6`） |

`inTradingWindow` 现在**只调用 `tradingDayState`**（此前它自己重写了一遍星期/假日判断 —— 实测那会让
"文件把 10-09 标成休市"在采样窗口这条快速路径上失效，定时器照采）。

## 3. 过期检查与可见告警（不得静默）

- 读取时校验**当月是否被覆盖**：未覆盖 ⇒ `warning = "交易日历未更新到本月（YYYY-MM）：文件里只有 … ⇒ 已退回内置规则。请按 README「交易日历维护」一节补上 "YYYY-MM": []（或本月休市日）"`，同时 `source` **如实写 `builtin`**（不许显示"外部文件"）。
- **三处可见**：① 快照 `summary` 追加 `｜⚠ …`（面板直接渲染 summary）；② 面板在摘要下方单独一行橙色 `⚠` 提示（`RescuePanel.tsx` 新增行）；③ agent 工具输出新增 `tradingCalendar` 段（来源/文件/已覆盖月份/当月已覆盖/告警）。
- 文件**不存在**不算"未更新"（首次使用不报错，`warning = null`）。

## 4. schema 校验 / 隔离留痕

| 类别 | 判据 | 处理 |
|---|---|---|
| 硬失败（隔离 + 退回内置） | JSON 解析失败；`v !== 1`；`months` 非对象/为空；月份键非 `YYYY-MM`；值非数组；日期非 `YYYY-MM-DD`；**日期不在所属月份**；**任意重复**（同月或跨月） | 改名 `trading-calendar.json.invalid-<时间戳>` + 同目录 `<名字>.reason.txt`（写明时间与原因）；`invalid.{reason,quarantinePath}` 进状态并显示 |
| 软提示（不隔离） | 条目落在**周末**（用户把整段假期含周末一起抄了） | 忽略该条 + `ignoredWeekends` 计数，界面/CLI 如实报数 |
