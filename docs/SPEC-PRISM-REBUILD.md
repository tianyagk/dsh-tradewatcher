# 棱镜（Prism）按设计稿重构 · 规格提取与实施计划（第 1 轮）

> 设计稿：`AGENT DESK · 自主交易代理工作台`（111 KB 单文件原生 JS，只读）。
> 本文件只做规格提取与拆分，不改 `src/**`、不写业务代码。
> 结论先行：设计稿是**三栏工作台**（人类约束 / Agent 决策 / 账户与绩效），与现有棱镜的“单列分段 + 右栏研判”结构差异很大；建议**整页替换**而不是增量修补。

---

## 0. 范围与不做（产品决策 · 2026-11-18 定稿）

1. **整页替换**：本重构是**棱镜页自身**的重做（`PrismPage.tsx` 整体替换为 `AGENT DESK` 三栏结构），**不新增页面、不新增导航入口**。旧棱镜的全部内容整页删除（逐条见 §7 删除清单），旧模块不做迁移、不做兼容。
2. **只接真实数据**：不得使用设计稿里的演示数值（`SIM-2026-11`、`deepseek-v4 · T=0.25`、示例持仓「中国海油」、示例事件等一律视为**占位**）。所有字段来自宿主接口；取不到的按红线落 `—`（单元格）+ `—（一句原因）`（区块），原因进 `title`/`aria-label`。演示环境标识、`--` 占位、`暂无…` 文案全部不落地。
3. **删除所有说明性内容**：
   - `AGENT DESK · 权责模型说明` 弹层（一句话 / Agent 拥有什么 / 人类拥有什么 / 边界是怎么生效的 / 人类不能做什么 / 演示提示）**整块删除**，不实现、不留入口。
   - 区块内的长句解释（如「每一次约束变更都会生成一条 CONSTRAINT 事件…」「没有手动下单入口…」）**一并删除**，只保留**一行口径**（≤ 24 字，如「约束变更即时生效」）。
   - 底部状态栏只保留四格事实（行情源 / 决策引擎 / 决策周期 / 约束版本），不加解释句。

**默认项确认**
- 设计稿没有的现有模块（**净值曲线卡、评估卡、模型选择、时点行**）**删除**；后端数据与接口保留（不删 host 侧能力，只删界面消费）。
- `添加持仓` 弹层**保留**（功能，不是说明性内容）。

**与补充默认的冲突/澄清（2 条）**
- 「删除模型选择」与「状态栏显示决策引擎」不冲突：删的是**可交互的选择控件**；状态栏里「决策引擎 / 约束版本」作为**只读文本**保留（设计稿自带，且属一行事实）。
- 「删除时点行」后，保存时点/骨架状态不再出现在棱镜页；如需排障请走插件自检，不在界面留痕。
