## 二、改动（删字优先，未新增任何文案）

1. **标签只留数据时刻**（`src/client/index.tsx`）：
   `label: () => (badgeState.stamp === '' ? '盯盘' : \`盯盘 · ${badgeState.stamp}\`)`
   —— `stamp` 是 `badgeView` 新增字段，**只有** `数据 HH:mm:ss[ · 已收盘]`，不含盈亏。
   ```
   改前：盯盘 · 当日盈亏 -2.29% · 数据 09:42:52
   改后：盯盘 · 数据 09:42:52
   ```
2. **徽标口径统一**（`src/client/badgeView.ts`）：徽标从 `-2.6` 改成 **`-2.3%`**（一位小数 + `%`），
   且 tooltip 里的百分比**用同一个舍入**（`-2.29% → -2.3%`，零值 `0.00% → 0.0%`，`≥10%` 仍 `10+%` 但补 `%` 标量纲）。
   ⇒ 徽标与 tooltip 现在是**同一口径、同一舍入**；`tone`（涨跌配色）不变。
3. **徽章与标签是两个不同的呈现，不再是同一事实的两种写法**：徽标 = 带色、紧凑的当日盈亏率（一位小数）；
   标签 = 数据时刻。金额（`dayPnl`）**不在**徽标里（此前 `+795.00 元` 那截早就被宿主截断过 ⇒ 早已不用），
   故不存在"金额 vs 百分比"的重复。
