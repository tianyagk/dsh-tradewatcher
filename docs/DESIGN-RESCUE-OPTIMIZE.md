# DESIGN-RESCUE-OPTIMIZE —— 护盘信号模块优化方案（研究 + 设计，只读）

**一行结论**：现状（六因子加权 + 时点系数 + 四档等级）在"量能/超大单/脉冲/持续性/背离/共振"这条主线上是**务实的**，
但缺三样东西：①**申购代理**（ETF 份额变化 × 净值 → 资金规模）——公开披露的"汇金买入 ≈ 份额增 × 均价"是唯一能给出
**规模量级**的口径，而我们只有规模（`nmc`/`f45`）没有份额；②**基线口径**（成交量 Z 分数 / 同时间点历史基线）——现在是
"同时点量能倍数 vs 20 日均额"，缺"相对自身波动的显著性"；③**误报分层**（调仓 / 被动申购 / 交割日 / 指数调整）。
性价比最高的三条提案见 §3 的 P1–P3。

### 1.2 等级与时点

- 基准线 `RESCUE_LEVEL_BASE = [35, 55, 75]`（`rescue.ts:299`）；等级 = 平静 <35 / 资金异动 ≥35 / 疑似护盘 ≥55 / 强护盘 ≥75。
- 时点系数 `timeCoefficient(elapsedMin)`（`rescue.ts:311`）：`≤0/<60/<120/<180/else = 0.4 / 0.4 / 0.7 / 1.0 / 1.1`。
- **等级线按时点系数缩放**（`levelLines`，`rescue.ts:307`）：早盘 0.4 ⇒ 线 87.5/137.5/187.5（**早盘不可能上疑似/强**）；
  尾盘 1.1 ⇒ 31.8/50/68.2。分数只作展示（`score = raw × coef`）。来源与断言见 `docs/AUDIT-IMPL48.md`。
- 封顶/否决：核心通道净流出达成交额 `-15%` ⇒ 封顶资金异动（`RESCUE_CORE_OUTFLOW_VETO`，`shared/model.ts:1415`）；
  指数 `+1.0%` 以上最多资金异动、`+0.3%` 以上不得强护盘；强护盘要求核心参与且 F2 ≥ 70。

### 1.3 采样、日历与新增数据

- 采样：常态 **30s**、尾盘（默认 14:30 起）**15s**（`rescue.ts` `activeIntervalSec`）；非交易日不采样（`docs/AUDIT-IMPL48.md`）。
- 交易日历：内置假日表 + 外部月历文件（`docs/AUDIT-IMPL49.md`）。
- 本轮新增（宿主，未接界面）：涨停/跌停家数（`marketExtras.limitCounts`）、两融双源（`marginCross`）、

## 3. 优化提案（按性价比排序）

### P1（最高性价比）申购代理：ETF 份额变化 × 净值 ⇒ 资金规模（新增独立因子/标注）

- **动作**：对六只宽基 ETF 记录**日频份额**（`shares`），计算 `净申购额 ≈ Δshares × 当日均价`；把
  "当日净申购额合计（亿元）"作为**独立展示项 + 共振/封顶的辅助判据**（不直接改权重）。
- **字段与来源**：`shares`（每日收盘后取一次；候选：交易所/基金公司披露页、第三方基金页）；净值/均价用我们已有的
  收盘价与 `nmc` 规模交叉校验（`Δshares ≈ Δ(规模)/净值` ⇒ 两者必须一致，不一致就如实标注）。
- **判定阈值**：**先不改等级线**。仅当"净申购额 ≥ 20 日均值的 3 倍"或"单日 ≥ 100 亿元"时，在归因里加一条
  `申购代理：宽基 ETF 净申购约 X 亿元（份额增 Y 亿份 × 均价 Z 元）`，并在 `疑似护盘` 及以上时作为**佐证**列出
  （不加分、不升级）。
- **误报/漏报影响**：误报来源是"份额增加≠汇金"（可能是做市/套利/其他机构）⇒ 文案必须写"**申购代理，不认定身份**"；
  漏报是份额数据滞后一天（日频披露通常在收盘后）⇒ 只能用于**当日复盘与次日确认**，不能盘中触发。
- **影响既有断言**：`src/host/fix3Highmed.test.ts`（无）、`src/host/rescueTradingDay.test.ts`（无）；
  **新增** `rescueShares.test.ts`；`RescuePanel` 快照类型（`shared/model.ts`）加可选字段 ⇒
  `src/client/rescuePanel.test.ts`（阈值同步断言）不受影响。

### P2 基线口径升级：同时点 Z 分数替代/补强"倍数"

- **动作**：为每只通道维护"**同一时刻**（同一 5 分钟刻度）近 N=20 个交易日的量能分布（μ, σ），
  得到 `z = (今日该刻度量能 − μ) / σ`；与现有 `timeAdjMult` **并列**输出，等级判据暂不改（先观察）。
- **字段与来源**：复用护盘采样环与 `rescue-log.json` 的历史（已有 21 天）+ 每日收盘后的分时归档；
  若历史不足 20 天 ⇒ `z = null` + 原因（"样本不足 N 天"），**不得**用当日的日频基线冒充。
- **判定阈值**：`z ≥ 2` 记"显著放量"；`z ≥ 3` 记"极端放量"（对应文献常用 ±3）。
- **误报/漏报影响**：Z 分数对**分布形态**敏感（成交额是右偏重尾）⇒ 建议同时看 z 与分位数（我们的 P75/P90/P95 标定
  已经是分位数口径）；停牌/复牌首日、指数调整日会产生合理异常 ⇒ 需与 P4 的日历过滤联动。
- **影响既有断言**：`src/host/rescueTradingDay.test.ts`、`p0.test.ts`（分位/窗口断言）需新增 Z 相关用例；
  现有 `f1` 标定断言不受影响（并列字段）。

### P3 误报分层：把"非护盘解释"显式排除（调仓 / 被动申购 / 交割日 / 指数调整）

- **动作**：在归因里加一段"**排除项**"，逐条给出"当天是否命中 + 依据"：
  ①**交割日**（股指期货 每月第三个周五）—— 命中日降低"脉冲"权重或加注释；
  ②**指数调整日**（沪深300/中证500 半年度调整，通常 6 月/12 月第二个周五生效）—— 权重重构会带来被动买卖；
  ③**大规模 IPO/配售缴款日**；④**ETF 分红除息日**（份额/规模跳变，会污染 P1 的 Δshares）。
- **字段与来源**：交易日历（已有）+ 一条"特殊日"表（可与 `docs/AUDIT-IMPL49.md` 的外部日历文件同源扩展，
  或新加 `special-days.json`）；指数调整名单可后置。
- **判定阈值**：命中①②时，**强护盘**要求额外满足"核心通道超大单 ≥ 高门槛且共振 ≥ 2"；命中④时 P1 的 Δshares
  当日**作废**（如实标注"分红除息日，份额跳变不可比"）。
- **误报/漏报影响**：已知交易日历式硬编码会过期 ⇒ 沿用"外部文件 > 内置表 > 不判定"与"过期只多算一天"的既有失败方向。
- **影响既有断言**：`src/host/rescueTradingDay.test.ts`（日历判定）、`src/host/tradingCalendar.test.ts`（外部文件语义）；
  `p0.test.ts` 的等级阈值断言需要新增"特殊日封顶"用例。

### P4 量价形态细分：把 F5 从"指数跌幅"升级为"形态 + 幅度"

- **动作**：用**价稳量增**（`|Δprice| ≤ 0.3%` 且量能倍数 ≥ P90）与**价跌量增**（`Δprice ≤ -0.5%` 且量能 ≥ P75）
  两个形态替代现在的单一"跌幅 ≥1% 满分"；形态判定要**同时**给"是"与"否"的判据（不许只给分）。
- **判定阈值**：见上（0.3%/0.5% 来自我们自己的 5 分钟标定曲线可得，非外部拍脑袋；落地前用 `scoreLog` 回放验证）。
- **误报/漏报影响**：阈值改动会改历史分数 ⇒ 必须在 `scoreLog` 上做回放，确认"过去 N 次信号"的等级分布不整体漂移。
- **影响既有断言**：`src/host/p0.test.ts`、`src/host/p1.test.ts`（F5 相关断言）+ 新增回放用例。

### P5 日内涨跌家数序列（复用护盘 tick 顺手落盘）

- **动作**：每次采样顺手取 `f104/f105/f106`（东财 ulist 已实测可得）落盘，形成日内 A/D 曲线；用于
  "护盘发生在普跌中的托底"这一形态判据（家数恶化而宽基放量 = 更有护盘意味）。
- **成本**：0 额外请求（复用既有行情请求的字段）；+1 落盘字段。
- **影响既有断言**：`src/host/marketExtras.test.ts`（新增）、`breadth` 相关断言不受影响（独立文件）。

### P6 分单口径的"内部矛盾检测"（低成本自检）

- **动作**：当"总量能倍数 ≥ P95"但"超大单净额 ≤ 0"时，在归因里加一句"**量增但无超大单净流入**"（可能是拆单/算法单
  或纯被动成交）；反之"超大单净额高但总量能平平"也标注。
- **理由**：这是对"按单笔金额分档"这一口径缺陷的**可检测代理**（见 §2-8）。
- **影响既有断言**：`fix3Highmed`（无）、`p0/p1`（F2 封顶逻辑已有，只需加文案）。

### P7（不建议）把"过去 N 次信号后表现"当预测

- 我们的 `forward` 回看是**描述性**的；外部证据（§2-7）显示同类资金流指标在控制当日涨跌后**预测力基本消失**。
  ⇒ 保持"描述 + 样本量 + 不作外推"的现口径，**不要**引入"信号后看涨概率"这类表述。

## 4. 红线（沿用并强化）

1. **不得把行为模式写成身份认定**：所有文案与工具输出只能说"符合护盘行为模式"，**不得**出现"汇金/国家队已入场"。
   P1 的申购代理尤其危险（份额增加 ≠ 汇金）⇒ 必须逐字带"申购代理，不认定身份"。
2. **缺数据 = 未取到 + 原因**（缺失四态），**不得 0 顶替**：份额缺失、Z 分数样本不足、家数缺失都走这条。
3. **不得为好看编数**：预测/代理量必须带口径（来源、样本天数、生成日、区间），如 `marketExtras.amountForecast` 的
   `caliber` 三件套。
4. **不得静默降级**：备用源没有分单资金流 ⇒ 封顶资金异动并写明（已有）；两级口径不一致 ⇒ 两个读数都留（已有）。
5. **不认定因果**：`forward` 回看只描述"过去 N 次之后发生了什么"，不给外推概率。

## 5. 反例与失效场景（每条提案的"何时会错"+ 可检测信号）

| 提案 | 失效场景 | 可检测信号（应写成断言/文案） |
|---|---|---|
| P1 申购代理 | ①做市/套利/其他机构申购被读成"国家队"；②**ETF 分红除息**导致份额/规模跳变；③份额≠规模÷净值（净值口径不同）；④份额数据滞后一天 | ①文案固定"不认定身份"；②除息日 Δshares 标"不可比"；③`Δshares × 净值` 与 `Δ规模` 相对差 > 5% ⇒ 标注不一致并两个都留；④快照带 `asOf` 日期 |
| P2 Z 分数 | ①停牌/复牌首日、新股纳入；②分布右偏重尾 ⇒ z 被极端值主导；③历史样本 < 20 天 | ①与交易日历/特殊日联动；②同时给分位数（已有 P75/P90/P95）；③`z = null` + "样本不足 N 天" |

| P4 形态细分 | ①阈值改动导致历史等级整体漂移；②分钟级噪声把"价稳"判成"价跌" | ①`scoreLog` 回放：等级分布变化 > 10% 必须人工确认；②用 5 分钟收盘价而非单笔价 |

| P6 矛盾检测 | 指数成分股调整日"量增无超大单"其实是调仓 ⇒ 误报为"异常" | 只在**归因**里陈述事实，不升级等级（P3 命中日再加注） |
| P7 外推 | 任何"信号后上涨概率 X%"的表述都会过度解读 | 工具/文档禁止该表述（现有文案已符合） |
