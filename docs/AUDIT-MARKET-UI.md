## 数据侦察（五项）
| 项 | 结论 | 依据 |
|---|---|---|
| ① 涨跌 5 类家数与占比 | **已有** | `breadth.current`（up/even/down）+ `marketExtras.limits.up/down.count`；占比 = 各类 ÷(涨+平+跌) |
| ② 涨跌分布 11 档 | **已有（需扫描）** | `GET /tradewatcher/breadth?dist=1` → `distribution.labels/counts`（11 档；要扫 ~56 页，故默认不开） |
| ③ 今日/昨日/预测累计成交额分时 | **无源** | 接口只有当日/昨日**总量** + 全天预测（`forecast`），没有逐分钟累计序列 ⇒ 该卡 `—（原因）` |
| ④ 分钟成交额较昨日增减（240 根） | **无源** | 今日分钟额可从指数趋势取，**昨日同分钟序列本地未留存** ⇒ `—（原因）`；`MINUTE_BARS=240` 已钉住，数据到位即画 |
| ⑤ 两融三项 | **已有** | `marketExtras.margin`（融资余额 / 融券余额 / 融资买入；深交所 + 东财双源） |

## 8 项断言（`src/client/marketV1.test.ts`，8 条全绿）
① 无「展开/收起」控件、`expanded = true`、六卡/因子/分时量能区块常驻（改回条件展开 ⇒ 败）；
② `.tw-rescue-cards` 同容器 `repeat(6,minmax(0,1fr))` + `<1100` 三列 + `<700` 两列（auto-fit ⇒ 败）；
③ `.tw-rescue-split` = `1fr 1fr`（上下堆叠 ⇒ 败）；
④ `.tw-mk-v` 22px、`.tw-mk-cell` padding 8/圆角 8、卡片 12/10、3px 竖条（28/12/10 ⇒ 败）；
⑤ `MINUTE_BARS === 240`；48 根输入 ⇒ 判不足（不画假柱）；
⑥ `DIST_BUCKETS === 11`、11 列布局、柱顶家数、档数不符走缺数据分支（缺档 ⇒ 败）；
⑦ `missingCellText('无昨日快照') === '—（无昨日快照）'`、缺值为 `null` 不是 0、不含 `0.00`；
⑧ `MarketPage.tsx` / `marketBlocks.ts` 无 `⚠`、无「免责/风险提示/仅供参考/不构成投资建议」。
