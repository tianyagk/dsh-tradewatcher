## 1. 口径（写死在代码里，改口径必须先改这里与断言）

| 项 | 取值 | 位置 |
| --- | --- | --- |
| 贪婪值窗口 | **60** 根（该市场**自身**日线，含当日） | `FLOW_GREED_WINDOW`（`globalFlow.ts:279`） |
| 贪婪值定义 | `(close − min₆₀) / (max₆₀ − min₆₀)` ∈ [0,1]；样本不足 / 区间为 0 / 有非有限值 ⇒ **null** | `greedOf()` |
| 动量分位窗口 | **5 / 20** 序列日（收益率 → **横截面**分位 0–1） | `FLOW_PREF_MOM_WINDOWS`（`:283`） |
| 分位口径 | 名次 1（最大）⇒ 1，末位 ⇒ 0；**并列取平均名次**；只有 1 个有值市场 ⇒ null（无法比较） | `percentileRanks()`（`:311`） |
| 偏好分 | `0.55 × 贪婪值 + 0.30 × 5 日分位 + 0.15 × 20 日分位` | `FLOW_PREF_WEIGHTS`（`:281`）/ `preferenceOf()`（`:337`） |
| 份额 | `偏好分 ÷ Σ 有值市场偏好分`（**0 是合法权重**：得 0 分的市场留在分母里） | `sharesFromScores()`（`:349`） |
| 缺样本 | 三个分量任一算不出 ⇒ 该市场**不进分母**，行级给原因 | `marketRaws` / `rowReasonOf` |

**曲线**：每一天都按「那一天为止的窗口」重算偏好分（贪婪值看当日往前 60 根；5/20 日动量在同一天做横截面分位），
因此曲线是**价格序列的纯函数**——不吃快照、不吃汇率、与规模无关。为了让曲线**第一天就有权重**，
`buildCurve` 额外多对齐 `FLOW_GREED_WINDOW` 天作为**热身窗口**（热身段只提供历史，不进输出）。
快照里新增 `pref` 字段（快照模式没有日线可算，必须存下来），口径标识升到 `v3:pref:cn,hk,us,jp,kr`
⇒ 旧口径快照整份作废并留痕（沿用 v0.74 的机制）。

**规模（仍展示、不进权重）**：KPI 磁贴「五市场合计规模」、市场表「规模」列、以及「规模折美元」的口径不变；
汇率只影响这一列（缺汇率 ⇒ 该行写「未折算」并说明"偏好份额不受影响"）。

## 4. 与参考版的差值（**不做调参**）

见 §0 表格。差值合计（四市场口径）：美国 **+24.72pp**、日本 −5.46pp、韩国 −6.16pp、A股 −2.50pp。

**为什么差这么多（如实说明，未调参）**

1. **贪婪值占 55%，而美国此刻在自身 60 日区间的 98% 分位**（0.98），日本 0.80、韩国 0.54、A股 0.00。
   仅这一项就给出 `0.55 × (0.98 − 0.80) ≈ 10pp` 的美日差，再加上动量分位差 ⇒ 美国自然领先。
2. 参考版的公式只公开了"情绪与趋势"这半句；**它到底怎么把 34.9% 给日本、20.8% 给美国，我们没有依据复现**。
   按用户给的比例（55/30/15）与"分位"的字面含义实现出来的分布，就是上面这一列。
3. 「分位」有**两种读法**，我都实测了（同一批真日线，见 §5 的敏感性检查）：
   A = **横截面**分位（本实现：把五个市场当天的动量排名归一化，与仓库既有「横截面排名」同一套口径）；
   B = 各市场**自身历史**分位（对过去 250 天的同口径收益率取分位，需要额外的历史窗口参数）。
   结果：A 给出 美国 45.5% / 日本 29.4% / 韩国 15.8% / A股 9.2%；B 给出 美国 44.1% / 日本 31.1% /
   韩国 20.1% / A股 4.7%。**两种读法都让美国 ~44–46%** ⇒ 差距的主导项是贪婪值，而不是分位读法。
   我选择 **A**：它复用仓库已有的横截面动量口径（不引入新的未定义窗口参数），且可复现。
4. 因此：**目标（不再被一家压平）达成**（91.2% → 45.5%，五家落在 10–50%），但与参考版的数值仍有明显差距，
   这是**口径不同**的结果，不是数据错误。若用户希望更贴近参考版，需要拿到参考版的完整公式（或明确要求
   换成分位读法 B / 调整权重比例）——那属于**改口径**，应由用户确认，我不按单一样本自行调参。
