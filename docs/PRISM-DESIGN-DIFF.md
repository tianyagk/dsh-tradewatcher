# 棱镜 · AGENT DESK 视觉/信息密度对齐 · 逐项差异清单（待确认）

> 基线：`v0.205.1`，`npm run check` 全绿 **1580/1580**，`npm run build` **73 片段**。
> 回包快照：`GET /tradewatcher/prism` 2026-11-19 19:57（真实数据，非设计稿演示值）。
> 设计稿：`AGENT DESK`（1511×1102 截图 + 111 KB 单文件）。本表只列差异与改法，未改任何 `src/**`。

## 0. 先说结论：三类差异

1. **结构性缺失**：顶部状态条、底部状态条、右栏「持仓/挂单」卡、中栏行情图与 AI 研判条——当前页完全没有。
2. **信息密度差 2–3 倍**：当前是 2 列 KV 文字列表（账户 4 项、绩效 5 项、决策流单行表格），设计是「大数 + 四格 + 进度条 + 时间轴卡」。
3. **数据缺口 5 处**（宿主回包没有该字段，按下表统一 `—` + `title` 原因，绝不写 0/编数）：
   - 持仓**行业**：`desk.positions.rows` 无行业字段；`state.exposure.rows` 只有行业聚合、无法回填单票（当前 f127 熔断，state=unavailable）。
   - **约束版本**：`settings` 无版本号字段（设计 `约束 v1`、底栏 `约束版本 v1`）。
   - **AI 研判结论 / 置信度**：`desk` 无研判结论与置信度；`state.runs[].summary` 是整篇长文，不是一句结论。
   - **逐条质证 chips**（`复审 0.71` / `702 tok`）：`desk.decisionFlow` 无 confidence/token；`performance.tokenUsage` 宿主恒 `null`。
   - **行情源 / 决策引擎标识**（`SIM-FEED` / `deepseek-v4 · T=0.25`）：`settings.model` 当前 `null`；无 feed 字段。
