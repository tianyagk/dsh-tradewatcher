# 因子层裁决（Lead）

> 依据：`docs/FACTOR-SPEC.md`、`docs/PRD-FACTOR.md`、`docs/AUDIT-AUTOT-HOST.md`、`docs/AUDIT-PRISM-UI-POLISH.md`。
> 裁决日期：2026-11-26。

## D-1 振幅口径（金融建模 vs PRD 冲突）

**裁决：采用日均振幅 `AMP20`，废弃「20 日区间振幅」。**

- 定义：`AMP20 = mean((high_i − low_i) / prevClose_i)`，窗口 20 个**已完成**交易日，前复权；
- 阈值：`AMP20 ≥ 1.2%`，且 `AMP20 ≥ 自身 120 日 40% 分位`（相对分位过滤低波标的）；
- 理由：区间口径实测中位 27.92%、3% 门槛通过 95%，UI 上等于不存在；日均口径中位 4.54%，1.2% 才有区分度；
- PRD 附录 A 的 `amp20Pct` 与 `3.00%` 门槛作废，以本条为准；UI 文案统一写「日均振幅」。

## D-2 ATR 门槛

**裁决：`ATR14% ≥ max(1.0%, 自身 120 日 40% 分位)`，不再用固定 1.5%。**

- 固定 1.5% 实测通过 91%，不构成筛选；
- 相对分位保证不同波动率的标的都能按自身状态判断；
- ATR 仍只作「波动状态」，不作收益预测。

## D-3 因子层边界

**维持 PRD D1：因子层只服务自动做T 的可执行性门槛；不选股、不评分、不排序、不进四路分析、不进主决策下单。**

- `candidateStats` 不改；
- 因子明细面板、决策流分组属于大改，需先出 HTML 原型并经用户审核；
- 第一期只做弹窗 3 处字段级文案（PRD U1/U2/U3），无布局变化。

## 施工顺序（P0 → P1）

1. **P0 信任底座**：审计 #10 关闭开关处理已成交腿、#11 收盘净持仓对账、#16 强制回补 T+1/涨跌停、#24 行为级测试、#20 autoT 文件保留上限；
2. **P1 最小可用**：`T_GATE_VERSION` + 常量表、`prism-factors` 快照（dailyFinal）、`gateOf()` 原因码、`placeAutoTPairs` 接 gate、payload `positions[].gate`、UI U1/U2/U3、影子日志；
3. **P2**：HTML 原型（因子明细）、反事实回放、影子 A/B 报告。

## 验收红线

- 缺数一律 `—` + 原因；不得用 0 冒充；
- 同一 cutoff 重算可复现；因子路径禁止 `fqt=0`；
- LKG/超龄报价在下单路径硬拒绝；
- 收盘净持仓与开盘差必须可核对，`forced-fail` 必须有落盘记录。

## 跨文档冲突裁决（2026-11-26 晚）

| 编号 | 冲突 | 裁决 |
| --- | --- | --- |
| C-1 | PRD D1「因子只服务 autoT」 vs 用户要求「供棱镜每轮决策」 | **P1 只做 autoT 门槛**；主决策接入列为 P2-1，必须先有因子日志与样本外验证，再由产品评审决定。 |
| C-2 | 日均振幅 `AMP20`（中位 4.54%） vs 区间 `RANGE20`（中位 27.9%） | **统一用 `AMP20` 日均口径 + 1.2% 阈值 + 120 日 40% 分位**；`RANGE20` 只作为诊断字段，不叫「振幅」、不进门槛。 |
| C-3 | PRD「不做收益回测」 vs 验证文档要求反事实回放 | 回测**只在离线脚本/报告中做**，不进 UI、不进产品验收；上线门槛仍需影子 A/B 证据。 |
| C-4 | ETF 涨跌停按 10% 猜测 | 禁止猜测：优先用行情 `f47/f48`；取不到写 `null` + 原因，`limit-locked` 只在明确锁死时触发。 |
| C-5 | 真价差/盘口无历史 | 不造假：回测只用 `costBps` 假设并做敏感性；UI 不展示「价差」为实时盘口。 |

**门槛版本**：统一 `t-gate-v2`（`AUTO_T_RULES.version`），16 个原因码；PRD 旧的 `t-gate-v1`（14 code、ATR 1.5%、RANGE20 3%）作废。实现入口 `src/host/prismGates.ts` 的 `evaluateAutoT()`，常量只在该文件定义。
