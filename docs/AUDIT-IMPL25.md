## 改动点（四步，逐条对应任务）

### 1. 统一价格空间（核心）
- 桶价来自 `fqt=1` 前复权序列；**报价快照是未复权的** ⇒ 比较前换算：
  `priceAdj = priceRaw × priceScale`，`priceScale = closeFq1_last / closeFq0_last`（**取同一根**最新日线：
  路由里对 `fqt=0` 的日线做 `days.find(d => d.date === lastFq1.date)`，**日期不等 ⇒ 不换算**、因子记 1）。
- 因子随结果返回（`priceScale`）；`== 1` 时是恒等（断言逐位比对，见下）。
- **没有**改用"未复权桶价"：分布仍在 fqt=1 空间算，只把现价搬过去。

### 2. 钉死"最新一根"语义
- `latestBarDate` = 递推窗口最后一根的日期，随回包返回；口径字符串写明：
  「"最新一根" = 递推窗口最后一根 ＆lt;日期＆gt;：最新一根用换算后的现价，展示日与它不一致时该展示日用当天收盘价，不混用」。
- 实现：`isLatest = (i === win.length - 1)` ⇒ 最新一根用 `priceUsed`，**历史展示日**用**当天收盘价**（`b.close`）；
  `barAlignsWithDisplay` 标注展示日是否就是最新一根。

### 3. 暴露输入（三值不一致的根治）
回包与面板口径现在都能读出四个字段：
```
priceUsed    盈利比例实际用到的现价（已换算到前复权空间）；不可得 ⇒ null
priceSource  quote = 报价快照（已换算）｜ close = 回落用展示日前复权收盘价
fqt          固定 1（桶价与现价都在这个口径下）
priceScale   换算因子（1 = 恒等）
另加 latestBarDate / barAlignsWithDisplay 两个语义锚点（见第 2 步）
```
面板的「盈利比例」tooltip 直接写：`现价 <值>（来源 quote|close，价格空间 fqt=1，换算因子 x，最新一根 <日期>）`。

### 4. 降级
- 报价缺失 ⇒ 回落**最新前复权收盘价**（`priceSource='close'`，如实标注，不静默）。
- 现价确实不可得 ⇒ `priceUsed = null` ⇒ 盈利比例 **`未取到`**（面板不再用 `—`；**不是 0**），平均成本照给。
