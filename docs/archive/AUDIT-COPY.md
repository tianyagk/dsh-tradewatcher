## 一、判定规则（机械可执行）

- **R1 默认删**：任何**常驻可见**（不在 tooltip/aria 里）且 ≥20 字的说明性文本 → 删除，或降为 tooltip。常驻 = 无降级、无缺失时也会出现。
- **R2 只留一处**：同一事实（口径 / 缺失原因 / 重试策略）全局只允许 1 处可见。发现 2 处以上 → 删到 1 处。优先级：**行级 tooltip > 面板级 hint > 正文长句**。
- **R3 不写废话**：与相邻数据重复、恒真或恒假的陈述 → 删（例：`今日买入 0 份…故可用少于持仓`）。
- **R4 空值不占位**：值为 0 / 空 / 全缺时派生的说明行 → 整行不出（`0.00`、`0.000%`、`—` 旁不再加句）。
- **R5 例外保留**：删除会造成**误读数据**或**误操作**的 → 保留，且压缩到 ≤14 字常驻、长文本进 tooltip（保留清单见四、K1–K10；不可删边界见五、第 1–7 条）。

行高换算（记账用）：常驻 `tw-hint` 11px×1.55 ≈ **17px/行**（≥60 字在 600px 宽下折 2 行）；行内 `tw-pps .meta` 10px×1.5 ≈ **15px/行**；`N` = 持仓只数（用户截图 N=8）。

## 五、动不得的 7 类边界（改文案时不许碰）

1. **YTD 基准**：前复权 / 指数按原始价格 / `baseKind='listing'` → 必须显示"上市首日"字样（`ytdView.ts:31`、`shared/model.ts:268`）。
2. **不复权不适用**（`QuoteDrawer.tsx:370,406,426`）：`不复权（该标的不适用）` 与该标的口径绑定，不能泛化成"不复权"。
3. **`missing` vs `transient`** 的区别（K1）：两档措辞必须可区分。
4. **折算口径**（`PortfolioPage.tsx:1184-1185`）：`按 1:1 悄悄加进去会让总额看起来完整、其实错了` —— 这句解释删了，"不折算"就会被当成 bug。
5. **不自动改账**（K3）。
6. **重试加重限流**（K2）。
7. **护盘概率口径**（K6）。

## 六、量化收益与验收

- 必修 M1+M2+M4：每只持仓删 3 行 `pps .meta` → **15px×3×N ≈ 360px**（N=8），约等于首屏少滚 4 只持仓。
- 必修 M3/M5/M6 + 应修 S1–S20：常驻"小作文"从 **~2 行/页** 降到 **0–1 行/页**；用户可见的 ≥40 字长句从 **~60 处** 降到 **~15 处**（其中 11 处是 tooltip）。
- 验收：持仓页 8 只、窗口 1440×900，改前/改后各截一图；标准 ① 无降级/无缺失时，行内 `tw-pps .meta` 不出现"口径类"文案；② 面板级 `tw-hint` 在无异常时 **0 条**；③ 同一句话全局搜索（`rg -c`）不得 > 1 处可见。

## 七、不确定项

- M1 的 `今日买入 0 份` 已由用户截图证实"整句照样渲染"；仅"N=0 是否为主要场景"取决于宿主 `availableQty` 是否把当日买入折为 0（`PortfolioPage.tsx:1099` 用 `Math.max(0, qty - availableQty)`）——若 `availableQty===qty`，则该句对**每只 T+1 持仓恒为假**。
