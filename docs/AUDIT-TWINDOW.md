## 一行结论
分时卡右上角新增 `做T` 开关（**按标的**记忆在 `prefs.tWindow`），打开后以**当日均价**为基准、`ATR%÷4` 为间距、
按 ATR% 自动 4/6/8 档画对称虚线网格（外两档 1.5px、内档 1px、`4 3` 虚线）、两侧标签 + 当前价实线气泡；
ATR 取不到 ⇒ **整组不渲染**并给一句原因（不回落默认值）；关闭 ⇒ 图里**一个节点都不加**。

## 8 项逐条
1. **开关**：`做T` 按钮在页签行右上（`fqControl` 左侧）；`prefs.tWindow[SECID]=true` 记忆，`tWindowPatchOf` 只改本标的键；关闭 ⇒ `tWin=null` ⇒ 图里不渲染任何网格节点（无虚线/标签/底色）。
2. **基准**：分时序列最后一点的 `avg`（当日均价线）；`quoteTs`（行情刷新节拍）进依赖 ⇒ 每次刷新重算一次。
3. **间距**：`ATR% = ATR14 ÷ close × 100`（`src/host/atr.ts`，Wilder TR 的 14 根简单平均），`间距 = ATR% ÷ 4`；取不到 ⇒ `{reason}`。
4. **档数**：`≤2% ⇒ 4；≤3.5% ⇒ 6；>3.5% ⇒ 8`；上下对称，`半跨度 = 间距 × 档数/2`；0 档不画（与均价线重合）。
5. **不可手动调整**：`tWindowOf` 的入参只有 `atrPct/avg`，没有档数/间距入参；无拖拽/输入/重设。
6. **不画成交点**、不含棱镜/挂单内容（源码断言）。
7. **标签**：左侧 `偏离% + 价格`（右对齐、间距 4px、等宽 tabular-nums）；右侧价格右对齐距线 6px；当前价气泡 rx=6、1px 边框、白底；买 `#4C6EF5` / 卖 `#E8590C`。
8. **徽标**：开关旁 `ATR x.xx% · n 档`（次要色）。
