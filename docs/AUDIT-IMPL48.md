# AUDIT-IMPL48 —— 护盘信号模块：交易日历 + 早盘等级线

**一行结论**：法定假日此前**完全没判**（周末判了、假日没判），且**非交易日的等级与当日分照写**（本地日志里
10-10 周六 21:44、10-11 周日 12:10 各落过一条 27~30 分的"平静"记录）；现按上交所 2026 年休市公告内置假日表，
休市日**不采样、零上游请求、不出等级（`level: null`，不是 0=平静）、不写当日分**，界面与工具文案显示
「休市（非交易日）+ 假期名」；早盘等级线改为**按时点系数缩放的唯一一处时点调整**（早盘 0.4 ⇒ 线 87.5/137.5/187.5，
尾盘 1.1 ⇒ 31.8/50/68.2）。40 条真实早盘样本复核：新旧口径等级**逐条一致（0 条差异）**，而**去掉缩放**会让
10-13 09:50/09:55/10:00 三条（原始分 58.8/58.8/56.16）直接跳到「疑似护盘」——正是要消除的过早触发。

## 第一节 审计现状（逐项 `文件:行号` + 实测）

### 1.1 现在怎么判断"在交易时段"

| 判据 | 位置 | 现状 |
|---|---|---|
| 采样窗口 | `src/host/rescue.ts:660`（原 `:556`）`inTradingWindow(ts)` | 星期（北京时间 `shWeekdayOf`，`dow===0/6` ⇒ false）+ `hhmm ∈ 09:25–11:35 ∪ 12:55–15:05` |
| 周末 | 同上 | **已处理**（`dow===0/6`） |
| **法定假日** | —— | ⚠ **完全没处理**：周中的假日照常进窗口 ⇒ 定时器照采、按时长照算 |
| 交易时段（展示层） | `src/host/time.ts:161` `inSession` | 同口径（工作日 + 09:25–15:05），同样**不含假日** |
| 复盘/定稿 | `src/host/time.ts` `lastCloseBoundary`/`isSettledOffline` | 按"最近一次 15:05"判定，与假日无关（休市日也会被判"定稿"，这正是假信号的来源） |

**实测（本地真实日志 `/home/hu/.dsh/dsh-tradewatcher/rescue-log.json`，21 天）**：`days` 里存在
`2026-10-10`（周六，2 条 `scoreLog`：21:44 与 23:21 各 30 分）、`2026-10-11`（周日，12:10，27 分）、
`2026-10-08`（周四 16:02，33 分）。周末的采样**不是**定时器干的（`inTradingWindow` 会拦），而是
`sampleNow()`（`:1264`）这条**按需路径没有窗口门禁** —— 面板/路由一刷新就采样、就出分、就写当日分。

### 1.2 时点系数

- 定义：`src/host/rescue.ts:296`（现 `:334`）`timeCoefficient(elapsedMin)`，`elapsedMin` = `sessionElapsed(hhmm)`
  （`:245`：09:30 起算，午休不计入，0–240）。
- 取值：`≤0 → 0.4`｜`<60 → 0.4`（09:30–10:30）｜`<120 → 0.7`（–11:30）｜`<180 → 1.0`（13:00–14:00）｜`else → 1.1`（14:00 起）。
- 适用范围：**只用于护盘评分**（`scoreRescue`），写入快照 `timeCoef` 与 `scoreLog.timeCoef`；
  用户截图里的 `时点系数 1.1` 就是它（`:548` 的 summary 与面板同源）。
- 接入点（改动前）：`:1435` 与 `:1472` 由 tick 传入，`score = clamp(round(raw × coef))`，等级线固定 `{35,55,75}`。

### 1.3 等级线

- 定义：`src/host/rescue.ts:458`（原）`const scaled: RescueLevel = score >= 75 ? 3 : score >= 55 ? 2 : score >= 35 ? 1 : 0`。
- **是否随时段变化**：改前=**分数**随时段变（乘系数）、线不变 ⇒ 判据里同时躺着"系数"与"线"两套机制
  （复核指出的双重计算风险正是这里）。改后=线随系数缩放、分数只展示。
- 防误报封顶（`:462-505`）：只能**降**等级，不会把假日变平静。

### 1.4 采样节拍与休市行为

- 常态 `intervalSec: 30`、尾盘（默认 `tailFrom: '14:30'`）`tailIntervalSec: 15`（`rescue.ts:1017` 默认配置、
  `:1117` `activeIntervalSec`）；窗口外循环等待固定 **30s**（`:1156`）。
- 休市（周末）行为：定时器**不采**，但 ①`sampleNow()` 照采（见 1.1 实测）；②`samplingWindow()` 的 `nextAt`
  只跳周末**不跳假日**（`:600-607`，逐日 `shWeekdayOf` 判定）⇒ 假期里会把"下次采样"指进假期。

### 1.5 现成的交易日数据源（逐个实测）

| 候选 | 可得性实测 | 结论 |

春节前后的**半日市**在 A 股**不存在**（港美股才有），因此本模块不处理半日市；**跨零点**：判据全部按北京
自然日/墙上时钟（`shDayOf`/`shHhmmOf`），跨零点后自动换日（`dayOf` 驱动 `todayKey`/滚动归档）。

### 1.6 选定的判据与失败退路（第二步实现的依据）

- **主判据 = 周末 + 内置法定假日表**（离线、确定性、零请求）。理由：① 假日的"有成交"在延时源上不可分辨
  （要额外依赖时间戳）；② 交易日历接口只有 HTML，抓取脆弱且每次启动都要联网；③ 失败方向可控 —— 表过期 ⇒
  只是"多采一天"，**不会**把真交易日误判成休市（漏采真实信号才是更糟的失败）。
- **退路**：表未命中 ⇒ 按交易日处理（保持旧行为）。②（指数当日无成交）**未接线**，见未做项。

### 2.2 早盘等级线（按时点系数缩放）

```ts
RESCUE_LEVEL_BASE = [35, 55, 75]            // 基准线（不变）
levelLines(coef) = { t1: 35/coef, t2: 55/coef, t3: 75/coef }
level = raw >= t3 ? 3 : raw >= t2 ? 2 : raw >= t1 ? 1 : 0   // 判据只看 raw 与线
score = clamp(round(raw × coef))            // 仅展示（面板/日志仍可复算）
```
- 早盘 0.4 ⇒ 线 **87.5/137.5/187.5**（>100 ⇒ 早盘**不可能**上「疑似/强」，硬保证"不过早触发"）；
  尾盘 1.1 ⇒ **31.8/50/68.2**（比基准更容易出等级，与"尾盘是护盘典型时点"一致）。
- **实测（40 条真实早盘样本，10-09/10-12/10-13 的 `scoreLog`）**：

| 口径 | 结果 |
|---|---|
| 旧（分数 × 系数比固定线） vs 新（原始分比缩放线） | **0 条差异**（`10-13 09:31/09:35/09:40/09:50/10:00…` 全部一致） |
| **去掉缩放**（原始分直接比 35/55/75） | **3 条跳到「疑似护盘」**：`10-13 09:50`（原始分 58.8）、`09:55`（58.8）、`10:00`（56.16） |

⇒ "同一份早盘数据，改前触发等级 vs 改后触发等级"：**改前**（无时点调整）= **等级 2 疑似护盘**；
**改后**（本实现）= **等级 0**；同一批 40 条里没有任何一条因为本次重构而改变等级（无回归）。
