# RESEARCH-MACRO —— 宏观制度与状态识别：棱镜的「宏观」能不能变成**可计算输入**

> **只读研究**：不改 `src/**`、不 commit、不装包、不重启。本文件是唯一写入。
> **基线**：HEAD `6b12b4d`（v0.148.0）。**评审对象**：棱镜四路研判里的 `a-macro`（`src/shared/prism.ts:114-119`）。
> **视角**：宏观制度与状态识别（利率与 10Y / 美元 / VIX / 两融与杠杆温度 / 市场宽度 / 指数与风格）。
> **边界**：**不提议新数据源**。凡涉及仓外数据源的，一律标「**建议（侦察另验）**」，本文件不做可用性断言。
> **标记**：**实测** = 读到代码/文档；**建议** = 需侦察确认；**未确认** = 本轮没验到。

---

## §0 结论（五行）

1. **能变成可计算输入，但必须拆成两件事**：**状态卡**（把确定性数字喂进去）负责"输入可计算"；**引用契约**（检查模型真的用了）负责"输出可验证"。只做前者 = 多一段文字，问题原样保留。
2. **现状是 0 个宏观数字**：四路分析共用同一段 context，而 context 只有【骨架/账户/持仓/行情/新闻】五段（`src/host/prismPipeline.ts:53-67`），行情只取自选+持仓的标的（`src/host/prismRoutes.ts:82-109`）——**指数、利率、美元、VIX、宽度、两融全都不在里面**。
3. **数据几乎不用找**：10Y 与美元指数（`src/host/marketExtras.ts:354`、`:394`）、杠杆温度（`src/host/leverage.ts:858`）、宽度分位（`src/host/breadth.ts:67`）、六只核心宽基 ETF（`src/shared/model.ts:1928-1934`）**都在仓内**。其中 **10Y/美元这两个导出目前零消费者**（全仓只有测试调用，`marketExtras.test.ts:136-145`）——是"有数据层、没产品层"的典型。
4. **VIX 是唯一没有真身的**：仓内只有 **VIXY（美股 ETF）**，走现有报价链 `107.VIXY → usVIXY`（实测记录 `src/host/tencent.ts:207-215`）；**没有 ^VIX 指数**。把 VIXY 当 VIX 报给用户是错口径（VIXY 有溢价与跟踪误差，且是收盘价）。
5. **棱镜是 one-shot 文本补全，不是 agent**（`prismPipeline.ts:107-113` 单次 `streamText`）⇒ 模型**不能自己调工具取数**，所以"强制引用"只能做**事后确定性检查**（可解析的引用行），不能做 tool-call 校验。这一条决定了下面所有设计。

## §1 一次研判的输入是怎么拼出来的（实测链路）

```
prismRoutes.ts:82  prismInputsOf()
   ├─ 自选 + 持仓 secid（:83-85）
   ├─ loadQuotes(secids)（:86 → :118 fetchQuotes，既有行情链，不新增源）
   ├─ 持仓文本（:88-91）／行情文本（:92-98）／待成交挂单（:99-106）
   └─ 账户快照 accountSnapshotOf（:59-80，七项数字带单位）
prismPipeline.ts:53 compileInput()  五段 = 骨架 / 账户 / 持仓 / 行情 / 金十新闻（:56-66）
prismPipeline.ts:105-116  四路并行：**同一段 context** + 各自 meta.prompt（:110）
prismPipeline.ts:124-142  汇总：同一段 context + 四路结论 + 强制条款（风险暴露/双侧/空单说明/JSON）
```

**结论**：`a-macro` 拿到的"宏观"只有两类——模型自己的先验知识，以及金十新闻里的文字。**没有任何一个可核对的数字**。这就是"宏观目前只是文字观点"的机制原因。

### 3.1 状态卡的形状（C1 的落地契约，供实现时照抄）

> 下面是**形状示例，数值非实测**（只说明「每维一行、带时刻、缺失自曝」的排版）。

```
【宏观状态卡（宿主计算，只读；缺数据写 — 并给原因）】
10Y：<值>%（<方向><幅度>）｜250日分位 <p>%（n=<N>）
USD：<值>（<方向><幅度>）｜分位 —（无历史序列）
VIX(VIXY)：<值>（<方向><幅度>）｜分位 —（本地快照 n=<k>，需 ≥20）
宽度：上涨 <u> / 下跌 <d>（<占比>%）｜60日分位 <p>%（n=<N>）
杠杆：显性融资 <r>%｜温度 <t>/100（2024 基准线）
风格：300/1000 相对强弱 <±x>%（20日）｜标签 <大盘占优|小盘占优|均衡>
护盘：<RESCUE_LEVEL_LABEL>（level <0-3>，score <s>）
数据时刻：<YYYY-MM-DD HH:mm>（10Y/美元为上一交易日收盘；杠杆截至 <YYYY-MM-DD>）
```

**四条硬规则**（写进实现，别写进提示词）：
1. 每行**必须**带"值 + 时刻"；分位不可用写 `—` + 原因（`无历史序列` / `本地快照 n=12<20`）。
2. **id 固定**（`10Y/USD/VIX/BREADTH/LEVERAGE/STYLE/RESCUE`），C2 的引用行只认这些 id。
3. 状态卡**只描述状态，不给建议**（"该买"属于决策层，不属于输入层）。
4. 卡里出现的每个数字都能被回放（C4 落盘），否则不许出现在卡里。

### 3.2 引用契约长什么样（C2 的落地契约）

```
【引用】10Y,BREADTH,LEVERAGE     ← 每路分析末尾必须有这一行
```
**校验（宿主，纯函数）**：`ids ⊆ 状态卡 id 集合` 且 `|ids| ≥ 2`；汇总额外要求"若 orders 非空，至少 1 个 id 属于 `{10Y,USD,VIX,STYLE}` 或 `{BREADTH,LEVERAGE}` 中的**非中性**项"（即方向不是"持平"）。
**不合格的处置**：`PrismAnalysis.macroMiss = { missingIds, reason }` + 页面在对应折叠标题旁标"未引用"，**不重试、不改写正文**。

> 为什么不用"数字正则"：模型会把 `2.6547%` 写成 `2.65%`/`约 2.7%`，正则要么误杀要么放过；**id 是人定的、机器可枚举的**，这才是可机检的契约（这条思路直接对应 `docs/RECON-PAPERTRADE.md` §1.8 的 `evidence.stance` —— **把"论据"变成可枚举对象**）。

## §4 落地顺序与可机检验收

| 批 | 内容 | 工作量 | 验收断言（宿主侧：纯函数 + 源码判据） |
|---|---|---|---|
| **批 1 · 数据层** | **C4**（快照结构落盘）+ **C5**（杠杆）+ **C6**（宽度）+ **C7 方向标签** | 1–2 天 | ① 快照里 7 个 id 各出现一次且带"数据时刻"；② 每个缺失项写 `—` + 原因（**注入"写 0"必败**）；③ 两融行含"截至 YYYY-MM-DD"（**注入"今日"必败**）；④ 宽度分位 `n < 40` 时不得出现百分数；⑤ `prism-runs.json` 回读后 `macro` 与写入逐字一致 |
| **批 2 · 决策层（核心）** | **C1**（注入 `compileInput`）+ **C2**（引用契约 + 闸门）+ **C3**（prompt 数据化） | 2–3 天 | ⑥ 注入后 context 含状态卡且**只含一张**（四路同一份，计数断言）；⑦ 引用行解析：合法 id 通过、未知 id 必败、`\|ids\|<2` 必败；⑧ 不合格 run 的 `macroMiss` 非空且**不触发重试**（上游调用数不变）；⑨ 快照与注入文本逐字一致（同一次 run） |
| **批 3 · 增强** | **C7 分位**（自建日快照 ≥60 交易日）+ **C8**（风格相对强弱） | 2–3 天 | ⑩ VIXY 标签必须含"ETF"（**注入"VIX 17.73"必败**）；⑪ 风格标签在 20 日窗口不足时写 `—`；⑫ VIXY/风格在无历史时不得输出分位（注入必败） |

**总成本**：批 1+2 约 **4–5 天**即可让"宏观可计算 + 可验证"成立；批 3 是增强。

## §5 明确不做（3 条）+ 红线清单

**不做**：
1. **不给棱镜加"宏观 agent 循环"**（让模型自己调 `tradewatcher_rescue` 等工具）。理由：现有架构是 one-shot 单次补全（`prismPipeline.ts:107-113`）；改成多轮会推翻"不自动重试"与"结果可落盘"两条既有约束，成本 L 且收益被 C1 覆盖。
2. **不把 VIXY 叫 VIX**，也不拿它的涨跌幅直接说"恐慌指数上升 X%"。要么标 ETF，要么等 ^VIX 源（**建议**）。
3. **不用宏观卡去"解释"已下的单**。宏观是**输入**，不是事后理由；若让模型引用宏观为订单辩护，等于给它一个新的洗白通道（`docs/RECON-PAPERTRADE.md` §4.2 第 1 条同一个问题）。

**红线（逐条都在这份设计里有对应处置）**：

| # | 红线 | 本设计怎么守 |
|---|---|---|
| ① | 缺失 ⇒ `—` + 原因，**不写 0** | 状态卡每维带 `kind: percentile \| change \| missing`，`missing` 不可渲染成数字 |
| ② | **读不到 ≠ 没有**（`readGuard.ts`） | 快照落盘带 `missing[]`；坏文件先隔离（沿用既有 `quarantineFile` 口径） |
| ③ | 棱镜**不自动重试**（`prismPipeline.ts:6`） | 引用不合格只标注，不重跑 |
