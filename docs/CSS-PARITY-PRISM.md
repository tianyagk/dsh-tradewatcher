## 仍未对齐 / 口径说明

- **分段选中态**：v3 设计 `.seg button.on` 为 `rgba(94,106,210,.14)` / 600；用户本轮明确覆盖为 `rgba(94,106,210,.18)` / 700 / `#2f3aa0`，表内按用户覆盖值记录。
- **净值坐标字号**：设计 v3 为 `11px`；实现取 `12px`，原因是仓库全局「密集字号阶梯」硬约束（12 / 12.5 / 13 / 13.5 / 14，低于 12 会失败）。对拍行按实现值 12px 记录，视觉差异约 1px。
- **图例 / 评估 n 字号**：设计 v3 为 `11.5px`；实现取 `12px`，同一 12px 下限约束。
- **深色模式**：设计稿只给了 light token（v3 没有 `[data-theme=dark]` 设计段）；深色行按现有 hybrid 深色 token 对拍，值见上表末尾 7 行。
