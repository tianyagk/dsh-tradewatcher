## 0. 一行结论

**部分能：能到「9:25 撮合结果：1 个价 + 1 个量」，不能到「9:15–9:25 的逐步撮合」。**

| 想拿的 | 能不能 | 依据（本文实测） |
| --- | --- | --- |
| 9:25 集合竞价**成交价** | ✅ **能** | 日线 `open` ＝ 腾讯 `m1` **09:30 根**的 O=H=L=C（3 个交易日**逐位相等**） |
| 9:25 集合竞价**成交量** | ✅ **能**（只走腾讯链） | 腾讯 `m1` 09:30 根的成交量：10-20 = **154.25 手**、10-21 = **516 手**；与腾讯分时首点 `0930` 的量逐位一致 |

### 1.2 (2) 9:15–9:25 之间的参考价/匹配量 —— **拿不到**（外部规则 + 历史不存在性 + 代码现状）

**(a) 交易所规则层面：这三项数据确实存在，而且属「即时行情」→ 免费网页接口之外**

外部资料（**非本机实测**，仅作口径依据）：

- 上交所《交易规则》5.2.1：「每个交易日 9:15 至 9:25 开盘集合竞价期间、14:57 至 15:00 收盘集合竞价期间，**即时行情**内容包括：证券代码、证券简称、前收盘价格、**集合竞价虚拟参考价格、虚拟匹配量和虚拟未匹配量**。」
  —— [上海证券交易所交易规则（2026 年修订）](https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml)
- 上交所《LDDS 系统竞价 Level-2 行情接口说明书》：开盘集合竞价时段内，UA3202 消息发送竞价数据 —— **申买价一/申卖价一 = 虚拟参考价格，申买量一/申卖量一 = 行情发布时刻的虚拟匹配量，申买量二/申卖量二 = 买方/卖方虚拟未匹配量。**
  —— [接口说明书 PDF](https://www.sseinfo.com/services/assortment/document/develop/c/10764038/files/8f5432f88c904455828b4804b9ae03d6.pdf)
- 上交所《IS120 行情网关 STEP 数据接口规范》：集合竞价时段内，**当前买入价和当前卖出价同时为虚拟开盘参考价格**。
  —— [规范 PDF](https://www.sse.com.cn/services/tradingtech/data/c/10832589/files/5ea26a2949c943a7ae2c9838c4c252bf.pdf)
- 深交所《交易规则》同款：开盘/收盘集合竞价期间即时行情含「**集合竞价参考价、匹配量和未匹配量**」。
  —— [深交所交易规则 PDF](http://docs.static.szse.cn/www/fund/guide/W020210331716400647184.pdf)

⇒ 由此得到一条**结构性结论**：竞价过程数据**不是"另一个接口"**，而是**复用普通快照的买一/卖一槽位**（价 = 虚拟参考价，量 = 虚拟匹配量，买二/卖二量 = 未匹配量）。
所以"有没有竞价专用接口"这个问题，正确答案是"**没有，数据在快照里**"。

## 3. 要拿到 9:15–9:25 逐步撮合，需要什么源

**免费源：没有。** 依据是本报告的实测（分钟序列最早 09:30；落盘缓存 0 条 09:2x；两家都没有竞价专用端点名）+ 交易所规则把这三项定义为「即时行情」内容。

**需要授权/付费的：**

| 源 | 给什么 | 状态 |
| --- | --- | --- |
| 上交所 **LDDS 竞价 Level-2**（UA3202 消息） | 买一/卖一价 = 虚拟参考价；买一/卖一量 = 该发布时刻的虚拟匹配量；买二/卖二量 = 未匹配量 | 交易所持牌产品 |
| **深交所 Level-2** | 集合竞价参考价 / 匹配量 / 未匹配量 | 持牌产品 |
| 券商行情 API、第三方 L2（东财 L2、同花顺 L2 等） | 同款字段 | 需开户/授权；东财在本插件里 robots 全站禁 |

⚠ 两点必须说清（免得把"授权源"想得太美）：
1. 即使拿到 L2，**粒度仍是"快照"**（按发布时刻给出该刻的虚拟匹配量），**不是逐笔委托明细**；逐笔委托/逐笔成交是 Level-2 的另一类消息，同样要授权。
2. 本插件是**只读、无账号**的形态；接 L2 需要凭据与授权协议，属于"另开一条有身份的链路"，不是加个 URL 能解决的。

- 若 `f9/f10` 恒 0、或恒等于昨收、或 `f9 != f19` ⇒ **未转发**，免费源彻底没有竞价过程数据。
